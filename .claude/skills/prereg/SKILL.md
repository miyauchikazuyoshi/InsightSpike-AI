# /prereg — 事前登録パッケージの生成

このプロジェクトの事前登録SOPは `docs/prereg/README.md` が正典。本スキルはその書式で
3点セット(prereg文書・ランナー・解析スクリプト)の雛形を作る。

## 手順

1. **先行文書を読む**: `docs/prereg/README.md`(原則)と、直近のprereg(現時点の最新書式は
   `docs/prereg/maze_sleep_ablation_v3.md`)を読み、書式・§構成・判定ロジックの流儀を把握する。
2. **ユーザーから確認する事項**(引数にあれば省略):
   - 主張(1文)とスコープ限定(何を主張しないか)
   - 予測 P1(Primary、1つだけ)と副次予測
   - 操作(1変数のみ)と対照、対象シード/データ(未使用であること)
   - 反証時の帰結(実装レベル/概念レベルの2層。試行予算との関係)
   - 探索的ランが先行している場合はその開示内容(§0)
3. **生成する3点**:
   - `docs/prereg/<name>.md` — 状態はDRAFT。§構成: 位置づけ/§0探索開示(あれば)/主張+スコープ限定/
     予測/反証条件表/実験設計(統計変更禁止、打ち切り・層別・標本拡張規則を事前定義)/
     主要指標/既知リスク/凍結手続き/§8結果(空欄)
   - `experiments/<line>/run_<name>.sh` — per-seed実行、skip-if-exists、1行サマリ出力(既存 run_sleep_ablation_v3.sh を参照)
   - `experiments/<line>/analyze_<name>.py` — 事前固定の統計(bootstrapシード固定・新しい値にする)、
     P3操作チェック、判定は§3の文言を機械出力、「検出力不足」と「反証」を区別
4. **解析スクリプトを検証**: 既存の類似実験データまたは合成データでスキーマテスト(縮退ケース含む)。
5. **コミット**(prereg 3点セットを1コミット)。
6. **凍結はしない**: パイロット→§6追記→**ユーザーの明示承認**を得てからFROZEN化。
   承認前に実験本体を実行しない。

## 禁止事項

- FROZEN文書の本文書き換え(追記のみ)
- 解析スクリプトの実行後変更(逸脱として記録が必要)
- 探索で使ったシード/データを確証対象に含めること
- パイロットや探索の結果を見てから予測・パラメータを「調整」すること(原則で固定する)
