## 4. 分析

### 4.1 「矛盾」の正確な構造

データレベルでは、A（α=0.001で微益）と D の positive 悪化（β=0.1）は**矛盾しない** — Phase 5 のスイープ自体が β=0.1 相当の強度で効果消失を示しているから。矛盾しているのは**物語**である：

- A/B/C は「学習済みTransformerはF最小化に近い状態で動作しており、弱い構造化圧が汎化を引き出す」という物語
- D は「F最大化＝DGトポロジー保存が益」という物語

そして**どちらの物語もデータが支えない**：
- A の +0.33pp は n=3、**4つのα条件に対する多重比較補正なし**。Bonferroni（α'=0.0125）では p=0.038 は**非有意**。Abstract の "causally improves" は過大。
- D の +1.38pp は n=1 で、baseline 自身の epoch1-2 ピーク（89.45）と同値 = 過学習前のbaselineに等しいだけの可能性。「3度の独立再現」は誤り：**β₁版は baseline 以下（−3.0pp）**、統一版は positive も改善しており方向弁別になっていない。
- random コントロールに負けている。

### 4.2 EPC項の死（外部レビュー指摘の検証）

percentile=0.9 の固定保持により**エッジ密度はほぼ一定**（soft sigmoid による閾値近傍の微変動のみ）。よって正則化勾配は実質 ΔH と ΔSP 項から来る。**この設計では3項の必要性も、ΔEPC の寄与も検証できない**。レビューの H-only アブレーション（F-reg vs エントロピー項のみ正則化）が理論の生死を決める実験であるという指摘は正しい。

### 4.3 概念整理：推論時ゲートと学習時正則化は別物

混乱の根に「Fの2つの使われ方」の未分離がある：

1. **推論時（受容ゲート）**: 候補統合の良し悪しを測る。F小=良い統合。迷路・RAGの全実験はこちら。**符号は理論で確定している。**
2. **学習時（正則化）**: モデル重みに「F を下げる/上げる圧」をかける。注意分布の構造を変える介入であり、**理論はこの符号を予測していない**（事前学習で獲得済みのDG構造を壊す可能性を含む）。

この区別を明文化するだけで、見かけの矛盾の半分は解消する。commit 6532184（demo の「上がる=良い」表現の削除）は同じ混乱への部分対処だった。

## 5. 判定

| 問い | 答え |
|------|------|
| 符号規約のバグか？ | **No**（両実装とも意図どおり） |
| 同じFか？ | ほぼ同じ（温度 0.1 vs 10.0、強度 α=0.001 vs β=0.1 が差分） |
| どちらの符号が正しいか？ | **現データでは決定不能**（n=1〜3、補正後非有意、対照に敗北、β₁版不成立） |
| 公開資料の矛盾は実在するか？ | **Yes**（A/B/C vs D）。即時修正が必要 |
