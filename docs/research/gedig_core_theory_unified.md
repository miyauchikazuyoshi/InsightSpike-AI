## 1. はじめに — スカラー直接扱いの工学宣言

> **3行要約**:  
> geDIG は、**構造コストと構造利得を確率分布に押し込めずスカラー量として直接扱う工学フレームワーク**である。  
> 既存研究（FEP, VAE, GNN, Information Bottleneck 等）はすべて構造情報を確率表現に写像して処理するが、本研究は構造量を構造量のまま取り扱う。  
> 「構造 ≡ 確率」の数学的厳密化は open problem（付録 D）であり、本研究の貢献は**スカラー F による構造制御の工学的実証**に徹する。

### 1.1 戦略宣言

既存の AI / ML 手法は、グラフ構造や位相情報を扱う際、**ほぼ例外なく確率分布への変換**を経由する:

- **FEP / Active Inference**: 構造をマルコフブランケットの確率モデルに写す
- **VAE / 潜在確率モデル**: 構造を潜在変数の分布に写す
- **GNN / Message Passing**: 構造をメッセージの期待値（確率的集約）に写す
- **Information Bottleneck**: 構造を相互情報量 `I(X;Z)` に写す
- **Graphical Models**: 構造を条件付き独立性の確率分布に写す

この「確率への押し込め」には計算上の利点（微分可能、ベイズ推論可能）があるが、
**構造特有の情報（特に位相）が落ちる**という本質的限界がある（§2 で Figure 1 により証明）。

geDIG は**構造量を構造量のまま保持するスカラー量 F** を用いる:

```
F = ΔEPC - λ·(ΔH + γ·Δβ₁)
```

`ΔEPC`（編集距離、組合せ論的）・`ΔH`（エントロピー、情報理論的）・`Δβ₁`（独立サイクル数、位相幾何的）
の3つを単一のスカラーに統合し、AG/DG 二段ゲートによる構造制御を行う。

### 1.2 本研究の範囲と留保

**本研究は工学的実証に徹する**。具体的には:

- スカラー F が AG/DG 二段ゲートによる動的構造制御を可能にすることを示す
- 複数ドメイン（迷路、OCR、RAG、Transformer）で F の有用性を実証する
- 既存手法（KL, FEP, VAE 等）が区別できない構造的事象を F が区別できることを示す（§2）

**本研究の範囲外**:

- 「構造 ≡ 確率」の数学的厳密化（情報幾何、MaxEnt、MDL との厳密対応）
- F の連続版（differentiable persistent homology 等による微分可能化）
- Amari 情報幾何や Kolmogorov 複雑性との一般的関係

これらは理論家に委ねる open problem として付録 D に記録する。

**統合素材**:
- `deductive_optimal_nn.md` §1（普通のNN vs geDIG）
- `gedig_origin_story.md`（トポロジカル再構成の直感）
- `thinking/matchstick_figure_v2.html`（Figure 1 の元データ）

## 2. 三項の独立性 — Figure 1 による核心の提示

> **3行要約**:  
> 同一の編集コスト `EPC = 1` に対して、位相 `Δβ₁` は +1 / 0 / −1 に分岐する（Figure 1、3ケース）。  
> **KL ダイバージェンスは ΔH しか測れないため、Case A（洞察）と Case B（力仕事）を区別できない**。これが既存確率論的手法の具体的失敗例。  
> geDIG は `Δβ₁` によってこの区別を可能にする。三項は数学の3基本概念（計量・測度・位相）に対応し、必要十分な組となる。

### 2.1 Figure 1: Matchstick Analogy（三項の独立性）

視覚化: **[thinking/matchstick_figure_v2.html](thinking/matchstick_figure_v2.html)**

| Case | 操作 | `EPC` | `Δβ₁` | `ΔH` | 判定 |
|---|---|---|---|---|---|
| **A** | 三角形完成（辺1本追加で閉路成立） | **1** | **+1** | +0.4 | **Aha! 洞察** |
| **B** | 棒の延長（辺1本追加、閉路なし） | **1** | 0 | +0.3 | 力仕事 |
| **C** | 四角形の1辺削除（閉路消滅） | **1** | **−1** | −0.2 | 構造崩壊 |

すべて編集コスト `EPC = 1` だが、位相変化 `Δβ₁` は完全に異なる振る舞いを示す。

### 2.2 KL の盲点（既存手法の具体的失敗例）

既存の確率論的手法は、本質的に `ΔH`（または相互情報量）のみを測る:

- **KL divergence**: 分布間の非対称距離、`ΔH` 系の量
- **ELBO / VAE**: KL + reconstruction loss、位相情報なし
- **FEP free energy**: variational free energy = KL + expected log-likelihood
- **Mutual Information (IB)**: `I(X;Z)` は条件付きエントロピーの差分

これらはすべて **Case A と Case B の区別ができない**:
- Case A の `ΔH = +0.4`、Case B の `ΔH = +0.3` は**ほぼ同じオーダー**
- 「どちらも情報が増えた」としか観測できない
- しかし Case A は**知識のトポロジーが変わった（閃き）**、Case B は**単に辺を1本延ばしただけ（力仕事）**

**この区別を失うことの工学的帰結**:
- 真の洞察と退屈な作業を同じ重みで扱う → 学習効率の低下
- 冗長な辺の追加を「情報増加」と誤判定 → 過学習
- 位相崩壊（Case C）の検出遅延 → 壊滅的忘却

geDIG は `Δβ₁` によってこれらを**工学的に検出・制御可能**にする。

### 2.3 既存手法との対比表

| 手法 | 測る量 | Case A/B 区別 | Case C 検出 | 計算量 |
|---|---|---|---|---|
| KL ダイバージェンス | 確率分布差 | ✗ | △ | O(N) |
| VAE / ELBO | KL + 再構成誤差 | ✗ | ✗ | O(N) |
| FEP / Active Inference | 予測誤差 (KL + 尤度) | ✗ | △ | O(N·d) |
| GNN message passing | 期待値集約 | ✗ | ✗ | O(E·d) |
| Information Bottleneck | 相互情報量 `I(X;Z)` | ✗ | ✗ | O(N²) |
| TDA (persistent homology) | 位相のみ | △ | ✓ | O(N³) |
| **geDIG (スカラー直接)** | **EPC + ΔH + Δβ₁** | **✓** | **✓** | **O(V+E)** |

geDIG の優位性は「すべて ✓ かつ線形計算量」の組み合わせ。
TDA は位相は見えるが計量・測度が欠け、計算量も重い。
KL 系は計量・測度は見えるが位相が欠ける。geDIG は**両者を統合した初のスカラー**。

### 2.4 Figure 2: Pruning Paradox（応用: NN 剪定への含意）

視覚化: **[thinking/matchstick_figure_v2.html](thinking/matchstick_figure_v2.html)** § Figure 2

K5 的完全結合グラフ（V=5, E=8, β₁=4）から中央ハブノードを剪定すると、
正方形（V=4, E=4, β₁=1）に還元される。

**Lottery Ticket Hypothesis (Frankle & Carbin 2019) の geDIG による再解釈**:

> 当たりチケット = `β₁` が最小でありながら `β₀ = 1`（全体接続性）を維持する部分グラフ

「削ると性能が上がる」という現象の**位相的説明原理**を geDIG は与える。
詳細は §5（β₁ 採用根拠）と §8（実験的裏づけ）で展開。

## 3. F 分解式の定義（正準形）

> **3行要約**:  
> 正準形は `F = ΔEPC - λ(ΔH + γ·Δβ₁)`（canonical 定義は `docs/gedig_spec.md`）。  
> 実装・論文本文ではこの形を使う。研究ノートでは簡約形 `F~ = EPC - (H + B)` を補助的に使う。  
> F を最小化する更新が「コストに見合う構造改善」を表し、`F < 0` は「閃き（insight）」の発火条件となる。

### 3.1 正準形と簡約形の区別

実装・論文と研究ノートで**同じ式の2つの表記**を使い分ける。

**正準形 (canonical)**:
```
F = ΔEPC - λ (ΔH + γ · Δβ₁)
```
- 論文本文、実装、ゲージ仕様（`docs/gedig_spec.md`）で使用
- `λ, γ` は quantile-calibrated なハイパーパラメータ
- 各項の単位・スケールは `docs/gedig_spec.md` の canonical 定義を参照

**簡約形 (shorthand)**:
```
F~ = EPC - (H + B)
```
- 研究ノートでの議論用（係数を吸収して構造を見やすく）
- `B` は第一 Betti 数 `β₁` の shorthand（generic な「bridge gain」ではない点に注意）
- 三つの読み方（§6）を議論する際の表記

両者は**係数 `λ, γ` の有無だけが違い、本質的な論証は同一**。
混在を避けるため、spec では正準形のみ、研究ノートでは簡約形を使う。

### 3.2 F < 0 の意味 — 閃きの発火条件

origin story に従うと、
```
F < 0 ⟺ 「コストを上回る情報利得が得られた」 ⟺ 「閃き（insight）」の瞬間
```

これは人間の「あ、わかった！」の認知プロセスを、スカラー量の符号変化として**工学的に観測可能な形**に落としたもの。

### 3.3 閾値校正と AG/DG（スカラーからゲートへ）

実装では F 値を直接使うのではなく、**quantile-calibrated な閾値 `θ_AG`, `θ_DG`** によってゲート判定する:

- **AG (Attention Gate)**: `g0 > θ_AG` のとき探索開始（0-hop の曖昧性検知）
- **DG (Decision Gate)**: `min{g0, g_min} ≤ θ_DG` のとき統合確定（multi-hop の確認）

ここで `g0` は 0-hop の F 値、`g_min` は multi-hop 候補の最良 F 値。
分位点校正によって、スケール不変性と異なるドメイン間での転用可能性を確保する。

詳細は `docs/gedig_spec.md` を参照。

### 3.4 SP 項の変遷 — ASP から β₁ へ

F 分解式のうち、SP（Structure Predictability）項は**歴史的に 2 度定義が変わっている**:

| 段階 | SP の定義 | 計算量 | 採用時期 |
|---|---|---|---|
| 初期（ASP 時代） | 平均最短路長（average shortest path）の変化 | O(V²⁺) | 〜2026-02 |
| **現行（β₁ 時代）** | **第一 Betti 数（独立サイクル数）の変化 Δβ₁** | **O(V+E) / O(1)** | 2026-02 以降 |

**ASP の問題点**（移行の動機）:
1. 計算量が O(V²⁺) で F 分解三項のうち SP 項だけが突出して重い
2. 構造の「結果」（平均距離）であって「構造そのもの」ではない
3. トポロジー + 幾何の混合量。構造と確率の分離という F 分解の目的と矛盾
4. 連続量。離散的な構造イベントを平滑化して情報を失う

**β₁ が位相不変量として優れる理由**は §5 で詳述する。
ASP 時代の実装は `--sp-mode asp|betti1|both` フラグで並行記録されており、
高相関（|r| > 0.7）が確認済み。論文では β₁ を本定義、ASP は脚注に留める方針。

### 3.5 「式は 1 つ、読解は複数、正準は 1 つ」の原則

§6 で詳述するが、F 分解式は **3 通りの読み替え**が可能（経済学的 / 物理学的 / 生物学的）。
ただし:

- **式は 1 つ** — `F = ΔEPC - λ(ΔH + γ·Δβ₁)` のみ
- **読解は複数** — 経済学的（正準）/ 物理学的 / 生物学的
- **正準読解は 1 つ** — `cost - gain`（経済学的）

この原則を崩すと、式の多義性が**強さ**から**曖昧さ**に転化する。
論文本文では読解 1 のみを使い、読解 2-3 は appendix / discussion に留める。

## 4. 三項の数学的意味: 計量 / 測度 / 位相

> **3行要約**:  
> `EPC` = **計量** (metric、組合せ論的編集距離)、`ΔH` = **測度** (measure、Shannon エントロピー)、`Δβ₁` = **位相** (topology、独立サイクル数)。  
> 3 つは数学の3基本概念の**原子**（これ以上分解不能な基本量）であり、いずれも**線形以下の計算量**。  
> ASP 時代の O(V²⁺) ボトルネックが β₁ 採用で O(1)〜O(V+E) に解消される。

### 4.1 三項＝三分野の原子

F 分解式の3項は、それぞれ数学の異なる分野の**基本単位**に対応する:

| 項 | 数学分野 | 位置づけ | 計算量 |
|---|---|---|---|
| `EPC` | 組合せ論 | グラフ編集距離、最小操作の数え上げ | O(V+E) |
| `ΔH` | 情報理論（確率論） | Shannon エントロピー、情報の基本単位 | O(N) |
| `Δβ₁` | 代数的位相幾何学 | 第一 Betti 数、ホモロジーの最低次不変量 | O(1)* |

\* 連結グラフの場合。一般グラフでは O(V+E)。

各項は各分野で**原子的**（これ以上分解不能な基本量）であり、
Kolmogorov 複雑性の意味で**最短の記述**になっている。

### 4.2 β₁ の定義と計算

**定義**:
```
β₁ = E - V + C
```
ここで `E` は辺数、`V` は頂点数、`C` は連結成分数。
連結グラフでは `C = 1` 固定なので `β₁ = E - V + 1`。

**意味**: 独立サイクルの数（グラフにおける「穴」の数）。

| グラフ | β₁ | 意味 |
|---|---|---|
| 木（tree） | 0 | 穴なし、冗長性なし |
| 三角形 | 1 | 最小の閉路 |
| ベンゼン環 (C₆H₆) | 1 | 6員環 |
| フラーレン (C₆₀) | 31 | 球面安定性 |
| K₄（完全4グラフ） | 3 | E=6, V=4, C=1 → 6-4+1 |
| DNA（n 塩基対） | ≈n | 遺伝情報量と β₁ が比例 |

**計算量の実際**:
- 連結グラフ: `O(1)`（E と V を数えるだけ）
- 一般グラフ: `O(V+E)`（連結成分のカウントが必要）

これにより、F 分解式全体が **O(V+E) の線形計算量**で評価可能になる。

### 4.3 三項の同時必要性（Figure 1 の再解釈）

§2 の Figure 1 により、3 つの項が独立であることは示された。改めて数学的に整理すると:

- **EPC のみを見る**と: 構造変更の**量**しか見えない（Case A/B/C すべて EPC=1 で区別不能）
- **ΔH のみを見る**と: 情報の**測度**しか見えない（Case A/B を区別できない、§2.2 の KL の盲点）
- **Δβ₁ のみを見る**と: 位相しか見えない（Case B の情報増加を見逃す）

3 項の合成により、**構造の計量・測度・位相のすべての側面**を計算可能な形で捉える。

### 4.4 計算量の線形性がもたらすもの

F 分解の3項がすべて **O(V+E) 以下**であることの工学的含意:

1. **リアルタイム制御可能** — 各ステップで F 再計算のコストが無視できる
2. **大規模グラフへのスケール** — 頂点数の2乗でなく線形に増える
3. **次元フリー** — グラフ化さえすれば、元空間の次元を忘れられる（768次元でも3次元でも同じコスト）
4. **増分計算が容易** — エッジ追加/削除の局所変化は `Δβ₁ = ±1 or 0` のいずれか、`ΔEPC = 1`

これは ASP 時代（O(V²⁺)）からの**計算量的にも本質的な改善**であり、
単なる定義の置き換えではなく、**スカラー F を動的制御信号として使うことを初めて可能にした**。

## 5. β₁ を採用する理論的根拠

> **3行要約**:  
> β₁ は**位相不変量・意味明晰・離散的・F 分解のスケーリング整合・基本量**の5つの理由で ASP を代替する。  
> 意味論: β₁ = 独立サイクル数 = 経路選択の自由度。構造的予測可能性の直接指標。  
> NN 剪定、材料科学、宇宙構造、相転移など**複数ドメインへの展開根拠**を持つ。

§4 で三項の数学的意味（計量・測度・位相）を示したが、本節では特に**位相項として β₁ を選んだ**理論的根拠を5つの観点から展開する。

### 5.1 位相不変量である

β₁ はグラフの連続変形（辺の再配置、重みの変更）で変わらない。
SP が測るべきは構造の**位相的性質**であり、β₁ はそれそのもの。

ASP（平均最短路長）は辺の重み・配置に大きく依存するため、位相不変ではない。
β₁ の位相不変性は、**スケール不変性**（15×15 → 51×51 で統計が保存）の数理的基盤となる。

### 5.2 意味が明晰である

```
β₁ = 独立サイクル数 = 経路選択の自由度
```

サイクルが1つ増える = ある2点間に独立な代替経路が1つ増える = **構造的予測可能性の増加**。
ASP の「平均距離が縮んだ」は、**なぜ縮んだか**（位相が変わったのか、重みが変わったのか）を語らない。

### 5.3 離散性が正しい

構造変化は本質的に離散事象。β₁ は整数。

- 「サイクルが1つ生まれた」= `Δβ₁ = +1`（正確な記述）
- 「辺が1本追加された」= `EPC = 1`（正確な記述）

ASP の連続的変化は**離散的構造イベントを平滑化**して情報を失う。
§2 Figure 1 の Case A/B/C が離散的に `Δβ₁ = +1/0/-1` に分岐するのは、この離散性の直接的帰結。

### 5.4 F 分解のスケーリングが整合する

三項の型:
- `EPC`（離散、組合せ論）
- `ΔH`（連続、情報理論）
- `β₁`（離散、位相幾何）

F 式の構造:
```
F = 離散 - λ(連続 + γ · 離散)
```

構造側（離散）と確率側（連続）の分離が**型レベルで保証**される。これは ASP 時代（全項が連続実数の混合）では得られなかった性質。

### 5.5 基本量である（Kolmogorov 複雑性の意味）

- ASP は全対間 BFS を集約した**派生量**（O(V²⁺) の計算、多数の局所量の集約）
- β₁ は引き算一回の**基本量**（`β₁ = E - V + C`、定数時間）

**Kolmogorov 複雑性の観点から、最短の記述が最も本質的な記述**である。
β₁ はその意味で位相情報の**原子**。

### 5.6 応用ドメイン

β₁ の採用は、複数ドメインに自然な説明原理を提供する。

#### 5.6.1 NN 剪定理論（Lottery Ticket Hypothesis の再記述）

Dense 層の β₁ ≈ n_in · n_out（巨大）。Sparse 層の β₁ は桁で小さい。

> **剪定 = ΔH を保ちつつ β₁ を最小化する操作**

**Lottery Ticket Hypothesis (Frankle & Carbin 2019) の再記述**:
> 当たりくじ = `ΔH` を保存する最小 β₁ の部分グラフ（木に近い骨格）

訓練と推論で β₁ の役割が逆転する:
- **訓練時**: 高 β₁ = 勾配の代替経路 = 探索に冗長性が必要
- **推論時**: 低 β₁ = 計算の無駄なし = 活用には β₁ 最小が最適

| 操作 | 位相的効果 | β₁ 変化 |
|---|---|---|
| 辺剪定 (weight pruning) | 穴を1つ潰す | `Δβ₁ = -1` |
| ノード剪定 (neuron pruning) | 穴を大きくまとめる | `Δβ₁ ≈ -(deg-1)` |
| Dropout | 一時的に穴を拡大 | 訓練時 β₁ が揺動 |
| Knowledge Distillation | 小さいスポンジに転写 | β₁ が桁で減少 |

この再解釈は §2.4 Figure 2（Pruning Paradox）と整合する。

#### 5.6.2 材料科学

| 構造 | β₁ | 化学的意味 |
|---|---|---|
| ベンゼン C₆H₆ | 1 | 芳香族性の源 |
| フラーレン C₆₀ | 31 | 球面安定性 |
| ダイヤモンド単位胞 | 9 | サイクル冗長性 = 硬度 |
| DNA（n 塩基対） | ≈n | 遺伝情報量と β₁ が比例 |

**破壊 = β₁ の減少**。
- 脆性破壊 = β₁ の急激な崩壊
- 延性変形 = β₁ を保存した形状変化

geDIG の AG 発火（曖昧性検知）が、材料破壊の予兆検知に直接使える可能性がある。

#### 5.6.3 宇宙の大規模構造

- Pranav et al. (2017, MNRAS) が cosmic web の Betti 数を計測
- Vazza & Feletti (2020, Frontiers in Physics) が脳ネットワークと cosmic web の**統計的類似**を指摘

F 分解は「なぜ似るのか」に対して「**同じ F を最小化しているから**」という説明を与えうる。
ただしこれは speculative（open problem）。

#### 5.6.4 Landau 型相転移

β₁ を秩序パラメータとすれば、F はそのまま **Landau 自由エネルギーの離散グラフ版**。
無秩序相（高 ΔH、低 β₁）→ 秩序相（低 ΔH、高 β₁）の遷移を F が記述する。

これは §6.2（Helmholtz 類推）および §6.3（生物学的読解、相転移 / 秩序パラメータ）と連動する。

### 5.7 計算パラダイムへの示唆

β₁ 採用は単なる指標変更ではなく、**計算のパラダイム転換**を含意する:

**5.7.1 変化検出**:
```
if Δβ₁ == 0:
    skip          # 位相不変、キャッシュヒット、O(0)
else:
    update F      # 位相変化あり、再計算、O(1)
```

位相が安定な領域 = 「無意識処理」。位相変化 = 「意識的処理」。

**5.7.2 有効次元の動的導出**:
正則 d 次元格子で `β₁/V ≈ d - 1`。したがって:
```
d_eff = β₁/V + 1
```
要素数 V と β₁ から系の**有効次元が O(1) で復元**できる。

**5.7.3 動的計算グラフ（NN の未来像）**:
現行 NN は入力によらず全層発火（All-to-All）。β₁ ベースでは:
- **どこを計算するか** → `Δβ₁ ≠ 0` の場所
- **何次元で計算するか** → `d_eff = β₁/V + 1`
- **残りは** → マスク（計算スキップ）

計算量が**入力の難しさに比例**する。

および [thinking/insight_beta1_dimension_free.md](thinking/insight_beta1_dimension_free.md)（次元フリー性と curse of dimensionality 回避）を参照。

## 6. F 式の3通りの読み方

> **3行要約**:  
> 同じ式 `F = EPC - λ(H + γ·B)` が**経済学的**（コスト-利得）・**物理学的**（Helmholtz 類似）・**生物学的**（相転移・位相秩序）の3通りに読める。  
> **canonical は読み 1（経済学的）** `EPC - (H + B) = cost - gain`。論文本文・実装はこれを主軸に置く。  
> 他2つは appendix / discussion 用。「**式は1つ、読解は複数、正準は1つ**」の原則を守る。

`origin story` で `F = cost - gain` と書かれた式は、抽象化すると簡約形 `F~ = EPC - (H + B)` になる。
この式は**括り方を変える**ことで、異なる理論的文脈で異なる意味を持つ。

### 6.1 読み 1: `EPC - (H + B)` = コスト - 利得（canonical、経済学的）

最も自然で、origin story に忠実な読み方。

```
EPC           = この更新はどれだけ構造コストを要するか
H + B         = その更新はどれだけ不確実性を減らし、位相数を改善するか
F が小さい    = コストに見合う更新
F < 0         = 閃き発火（§3.2）
```

**この読みが canonical である理由**:

- origin story と完全に整合する（人間の直観「`F < 0` = あ、わかった!」）
- AG/DG 実装（§3.3）に直接落ちる
- 迷路 / RAG / OCR / Transformer すべてで使える
- 最も**検証可能**で、最も**工学的**

**使用方針**: 論文本文、spec、実装説明、発表ではこの読解を主軸。

### 6.2 読み 2: `(EPC - B) - H` = 構造 - エントロピー（物理学的、Helmholtz-like）

B を `β₁` として読むと:

```
EPC - B   = 冗長サイクルを除いた本質的構造変化（骨格の変化）
H         = なお残る未整理性・エントロピー
```

**Helmholtz 自由エネルギー `F = U - TS` との対応**:

| Helmholtz | geDIG（読み 2） | 意味論 |
|---|---|---|
| `U`（内部エネルギー） | `EPC - B = EPC - β₁` | 冗長サイクルを除いた本質的構造変化、骨格の真のコスト |
| `T`（温度） | `λ`（情報温度） | 利得の相対重み、annealing スケジュール候補 |
| `S`（エントロピー） | `H`（Shannon エントロピー） | 確率側の未整理性 |
| `F < 0` で自発過程 | `F < 0` で閃き発火 | 「起こりやすい」方向 |

**なぜ `(EPC - B) - H` が正しい Helmholtz 対応か**（読み 1 の `EPC - (H+B)` ではなく）:

- `EPC` 単体は「編集の総量」だが、そのうち `B = β₁` 分（冗長サイクル生成/消失）は位相秩序の変化であって、内部エネルギーの本質ではない
- `EPC - β₁` が「冗長サイクルを除いた本質構造の変化コスト」となり、熱力学的な**内部エネルギー U** の自然な離散類推になる
- 残る `H` が熱力学的**エントロピー項 TS** に対応する

これは **literal な熱力学同値ではなく、operational correspondence**（操作的対応）であることを強調する。FEP 類推と同じ留保を入れる。

**λ の情報温度としての動的制御**:

Helmholtz 読みを受け入れるなら、λ は単なる静的ハイパーパラメータではなく **温度** として振る舞う。これは **simulated annealing (SA)** と構造的に一致:

- SA の受容確率: `P(accept) = exp(−ΔE / T)`
- geDIG の受容判定: `F < 0`（決定的閾値版）

**検証可能な仮説 H_temp**:
> λ の温度スケジューリング（Wake 初期で高、Sleep で漸減、Wake' で低）は、固定 λ よりも迷路/RAG の探索効率を改善する。

詳細は [thinking/gedig_formula_three_readings_20260306.md](thinking/gedig_formula_three_readings_20260306.md) §4.3-4.4 参照。

**使用方針**: FEP / MDL / Helmholtz の discussion、appendix、理論的エッセイ、**温度スケジューリングの実装検討**で有効。

### 6.3 読み 3: `(EPC - H) - B` = 内部状態 - 位相（生物学的、相転移）

`EPC - H` を「情報的に説明しきれない構造変化」と読み、`B` を位相秩序 / order parameter 側に置くと:

```
EPC - H   = 情報的に説明できない構造変化（情報を流すためでもないのに存在する構造）
B = β₁    = その残差を説明する位相秩序
```

**例**: シロアリ塚の換気トンネル。情報処理を担わないのに存在する位相的秩序。
β₁ が「なぜこの構造がそこにあるか」を説明する。

**相転移的な読み**:

この見方で geDIG は、
- 高エントロピーな**探索相**
- 構造が固定された**秩序相**
- その境界で起こるレジーム変化

を記述する式として見えてくる。

β₁ を秩序パラメータと見る **Landau 的な読解**とは、この読みが最も近い（§5.6.4 参照）。

**使用方針**: phase transition 的な discussion、β₁ / routing / topology の役割整理、speculative note で有効。**現時点では最も遠い読解**であり、論文本文の主軸には据えない。

### 6.4 3つの読み方の関係

| 読み | 形 | 主な意味 | 使う場所 |
|---|---|---|---|
| 1 | `EPC - (H + B)` | コスト - 利得（経済学的） | **canonical / 実装 / 本文** |
| 2 | `(EPC - B) - H` | 構造 - エントロピー（Helmholtz） | FEP/MDL/Helmholtz 解釈、λ 温度制御 |
| 3 | `(EPC - H) - B` | 内部状態 - 位相（相転移） | 相転移・秩序変数の議論 |

重要な順序:
- **式は 1 つ** — `F = EPC - λ(H + γ·B)` のみ
- **読解は複数** — 経済学的 / 物理学的 / 生物学的
- **正準は 1 つ** — 読み 1（経済学的）

この順序を崩すと、式の多義性が**強さ**から**曖昧さ**に転化する。

### 6.5 書き方の原則

- **spec では混ぜない** — canonical 形のみ、読解の多義性は discussion に閉じ込める
- **paper 本文では reading 1 を使う** — AG/DG 制御との整合、実験との直結
- **reading 2/3 は appendix / discussion / thinking note に置く** — 類推の柔軟さを保ちつつ、本文の厳密さを守る

これにより、式の多義性を**強さ**として使いつつ、**曖昧さ**に落とさずに済む。

### 6.6 まとめ

geDIG 式の強さは、同じ式が:
- 工学的には `cost - gain`（読み 1、canonical）
- 理論的には `structure - entropy`（読み 2、Helmholtz）
- さらに位相的には `internal-state - topology`（読み 3、相転移）

として読める点にある。

ただし、出発点はあくまで origin story の「**コストに見合う更新だけを受け入れる**」という設計原理である。
したがって、**第一の読み方を正準とし、他は解釈として従える**のが最も強い。

## 7. Wake-Sleep-Wake ループと演繹的 NN の導出

> **3行要約**:  
> §1 の戦略（スカラー直接扱い）と §2-4 の三項合成から、自然に導かれるアーキテクチャが **Wake-Sleep-Wake ループ**であり、その特殊形が**演繹的 NN**である。  
> 演繹的 NN = 明示的な F と制約から「良い構造」を決める枠組み。帰納的 NN（重みの勾配学習）との違いは、構造を先に作る vs 後から刈り込む。  
> 演繹的 NN は頂点ではなく、**スカラー直接扱い戦略の帰結**として位置付ける。

本節は、§1-6 で確立した戦略・三項・読み方から、具体的なアーキテクチャがどう導出されるかを示す。

### 7.1 論証の流れ（導出順）


### 7.2 AG/DG 二段ゲート

スカラー F による構造制御の**最小機構**として、2 つのゲートが要請される。

**AG (Attention Gate)** — 0-hop の曖昧性 / 新規性検知:
- `g0 > θ_AG` のとき探索開始
- 意味: 「**今の知識では説明できない**」という信号の検出
- origin story での「あれ？」に対応

**DG (Decision Gate)** — multi-hop の有効性確認:
- `min{g0, g_min} ≤ θ_DG` のとき統合確定
- 意味: 「**このショートカットは本当に効く**」という確認
- origin story での「なるほど、繋がった」に対応

閾値 `θ_AG`, `θ_DG` は**分位点校正**によって決める。
これにより、異なるドメイン（迷路・RAG・Transformer）で同じ仕様を使える。

**神経伝達物質との対応**（computational analogy）:
- **NA（ノルアドレナリン）** ≒ AG（覚醒・曖昧性検知）
- **DA（ドーパミン）** ≒ DG（報酬・確信）

> <small>注: これは implementation design としての類推であり、生理学的同一性の主張ではない。
> 詳細は [thinking/gedig_cognitive_steam_engine_20260306.md](thinking/gedig_cognitive_steam_engine_20260306.md) を参照。</small>

**なぜ 2 段ゲートなのか**:

閃きには**2 つのフェーズ**がある:
1. **違和感の検知**（AG）— 既存知識では説明できない何かがある
2. **構造的検証**（DG）— 新しい接続が本当に有効か確認

この 2 段構造は、1 段ゲート（単一閾値）では表現できない**時間的な分離**を持つ。
探索的活性化 → 確認的コミットという**異なる性質の処理**を分離することで、
過剰探索（AG だけ）や時期尚早なコミット（DG だけ）を避ける。

### 7.3 Wake-Sleep-Wake の 3 相ループ

AG/DG ゲートを常に動かすだけでは不十分。**時間スケールの異なる処理**が必要になる。

**Wake 相（探索・経験蓄積）**:
- AG/DG 発火による候補エッジの評価
- 局所近傍での F 計算
- 重要なエッジ候補のログ保存
- 「どの遷移 / 結線が意味があるか」をログとして残す

**Sleep 相（圧縮・再配線・剪定）**:
- Wake で蓄積したログを用いたオフライン最適化
- **再配線**: 有効なショートカットの内在化（多ホップ → 0-hop への圧縮）
- **剪定**: コストに見合わないエッジの削除（`F > 0` が続くエッジ）
- **まとめ**: 冗長経路の圧縮

**Wake' 相（再利用・検証）**:
- Sleep で得た構造 / 方策を次の Wake で使用
- ステップ削減 / 探索コスト削減として観測される

**CLS 論との対応**:

この 3 相ループは **Complementary Learning Systems 論**（McClelland, McNaughton & O'Reilly 1995）の工学的実装に相当する:
- Wake = 海馬的なエピソード蓄積
- Sleep = 新皮質的な意味抽出（consolidation）
- Wake' = 抽出された semantic 知識の再利用

エピソードから共通構造（≒語彙・概念）が **AND 蒸留**として emergent に立ち上がる。
これは Tulving (1972) の episodic / semantic memory 区別を連続プロセスとして実装する枠組み。

詳細は:
- Part 3（`phase2/` 配下）の Sleep 実装仕様
- Part 2 [gpt_bert_gedig_perspective.md](gpt_bert_gedig_perspective.md) のエピソード起点論

### 7.4 演繹的 NN の操作的定義

Wake-Sleep-Wake ループを「**ニューラルネットの学習則**」として見ると、
これは従来の勾配下降法とは異なる **演繹的 NN** の構築機構になる。

「演繹的」という言葉の**ドリフト**（素材間で微妙に異なる定義）を、単一定義に収束させる:

> **演繹的 NN**: 明示的な F と制約から「良い構造」を決める枠組み。
>
> - **対象**: エピソード（ノード）と関係（エッジ）から成るグラフ G
> - **目的**: `F(G)` の最小化
> - **制約**: 到達可能性・予算（計算量・エッジ数・時間）
> - **探索法**: 局所探索 + コミット（AG/DG）による近似最適化

厳密な全球最適証明ではなく、**operational な演繹**である点を明示する。
この定義は、`thinking/deductive_optimal_nn.md` での「演繹」、`gedig_origin_story.md` での「トポロジカル再構成」、
`thinking/betti_number_adoption_memo.md` での「位相不変量による最適化」を**同一のもの**として統合する。

### 7.5 帰納的 NN との対比

geDIG の演繹的 NN と、従来の帰納的 NN（LLM / GNN / CNN など）は、以下の軸で対照的:

| 軸 | 帰納的 NN (LLM 等) | 演繹的 NN (geDIG) |
|---|---|---|
| 学習対象 | **重み** | **構造**（グラフ） |
| 最適化 | 勾配下降 | 局所探索 + コミット (AG/DG) |
| 構造 | 固定（事前設計） | 動的（F で生成） |
| 教師信号 | 外部ラベル | F + 正例 / 負例（§7.6） |
| 学習ループ | train / inference 分離 | Wake-Sleep-Wake 統合 |
| 表現学習 | 重みに暗黙 | グラフに明示 |
| スケール則 | データ・パラメータ数 | 構造コスト・位相量 |
| 解釈可能性 | 低（ブラックボックス） | 高（F の符号・三項の寄与） |

**両者は対立ではなく補完**:

- 帰納的 NN は**過去の分布を学ぶ**のが得意（大規模データからの統計的圧縮）
- 演繹的 NN は**新しい構造を発見する**のが得意（矛盾検知・トポロジカル再構成）
- LLM に curl 検出を加えた「**帰納 + 演繹の統合**」として autonomous discovery machine が構想されている（詳細: [thinking/gedig_autonomous_discovery_machine.md](thinking/gedig_autonomous_discovery_machine.md)）

### 7.6 正例 / 負例を構造最適化の教師信号に

演繹的 NN の**学習信号**は、外部ラベルではなく **F と自己教師信号**から生成される。

Wake で蓄積したログ `(state, action, next_state)` に自動的にラベル付与:

**正例（+1）**:
- Sleep plan 上の遷移（ゴール到達に寄与した遷移）
- ログ: `sleep_guided=true`

**負例（-1）**:
- **revisit**（2回目以降の訪問）= ループ / 無駄足 / 探索の失敗
- ログ: `cortisol_fire=true, cortisol_reason=revisit`

これが**構造最適化の自己教師信号**となる。

**ベクトル表現の自律化への発展**:

ベクトル（エピソード表現）を固定手設計から自律化すると、以下のループが作れる:

1. Wake で正例 / 負例のログを集める
2. Sleep でログから encoder（表現）を更新
3. 次の Wake で 0-hop が賢くなり、AG が減り、DG が早く成立する

つまり「**多ホップで見つけたショートカットが、0-hop の直感に内在化する**」。

この時点で、geDIG は NN そのものというより **NN を訓練する教師（自己教師生成器）**に近づく。

### 8.1 迷路 PoC — スケール不変性

**目的**: 完全に制御された環境で `ΔEPC`, `ΔIG` を厳密計算し、F 予測と実際の探索行動の対応を検証。

**設定**:

- ベースライン: ランダム探索、固定 heuristic
- メトリクス: 探索ステップ数、無駄枝剪定率、最短路到達率、AG/DG 発火統計

**結果**:

| サイズ | 成功率 | ベースライン比 |
|---|---|---|
| 15×15 | **98%** | 大幅改善 |
| 25×25 | 検証継続中 | 大幅改善 |
| 51×51 | 検証継続中 | 大幅改善 |

**理論予測との対応**:
- F 値の分布が 3 サイズで**統計的に保存**（スケール不変性）
- AG 発火がデッドエンドで即座に起こる（理論通り）
- DG 発火がループ閉鎖時に起こる（理論通り）

これは §5.1 の「β₁ の位相不変性がスケール不変性の基盤」を実証する結果。

> 📂 詳細: `experiments/maze-query-hub-prototype/`

### 8.2 OCR — 構造先行設計の有効性

外部プロジェクト [vector-based-cnn-ocr](https://github.com/miyauchikazuyoshi/vector-based-cnn-ocr) での検証。
これは §1 の「スカラー直接扱い / 構造を先に与える」戦略の**最も決定的な実証**。

**設定**:
- タスク: Font → 手書き cross-domain transfer（文字認識）
- geDIG 適用: κ, θ フロー場を手設計で CNN に与える（§7.6 のベクトル固定版）

**結果**:

| 指標 | geDIG 版 | 標準 CNN |
|---|---|---|
| パラメータ数 | **18K** | 数百万 |
| 精度 | 73.53% | 同等 |
| 構造発見コスト | 解析的に除去 | 学習で獲得 |

**geDIG 概念との対応**:

| geDIG 概念 | OCR 実装 | 性能貢献 |
|---|---|---|
| §1 構造 first | κ, θ フロー場の手設計 | 18K params 達成 |
| §4 正例 / 負例 | skeleton flow / skeleton error | error_map で +0.50pt |
| §5 β₁ 利用 | β₀β₁ side channel | 2ch で +0.51pt |
| AG ゲート | error_map（探索的偏差情報） | 11ch, +0.50pt |
| DG ゲート | β₀β₁ side channel（確定位相情報） | **2ch, +0.51pt** |

### 8.3 DG > AG の情報効率（理論予測の確認）

OCR 実験で観測された**重要な結果**:

```
AG (error_map):       0.05 pt/ch
DG (β₀β₁ channel):    0.26 pt/ch
                      ↓
DG は AG の 5 倍の情報効率
```

**理論的解釈**:
- DG はコミット（確定した構造）→ **圧縮された確定情報**は効率的
- AG は探索（未確定の方向）→ **拡散した探索情報**は冗長性を含む

これは §7.2 の AG/DG 二段ゲート設計が**単なる便宜ではなく、本質的に異なる性質の情報を扱う**という主張を実証する。

### 8.4 BN = 暗黙的 predictive coding の発見（副次結果）

OCR 実験で興味深い副次発見:

| 設定 | error_map 貢献 |
|---|---|
| BatchNorm あり | +0.50pt |
| BatchNorm なし | **+0.75pt**（+0.25pt 差） |

**geDIG 的解釈**:
- BN は暗黙的に「予測 → 偏差」計算を行っている（暗黙的 AG）
- 明示的な error_map（明示的 AG 信号）と**干渉**する
- BN の variance normalization が **AG の precision**（「どこが曖昧か」の空間的精度）を破壊する

これは **明示性 vs 暗黙性**の問題として、既存 NN への geDIG レンズの適用例になる。

**設定**: HotpotQA Lite Suite、500 query、multi-hop QA

**結果**:

### 8.6 Transformer 層別解析 — 現状 negative result（正直な報告）

**目的**: Attention graph を geDIG で評価し、層間の F 動態から Transformer の内部を理解する。

**仮説**:
- **H1**: 実際の Transformer attention は、ランダム/一様/局所ベースラインと異なる F 統計を示す
- **H2**: 深い層ほど F とその内訳の傾向が変わる
- **H3**: Attention 介入（スパース化/ノイズ付加）は、ΔF に応じて下流性能を変化させる

**現状の結果（正直に）**:

| メトリクス | distilgpt2 | gpt2 | gpt2-medium |
|---|---|---|---|
| `delta_r2_struct` | **-0.73** | **-0.18** | **-0.16** |

すべて**負値**。これは「構造指標が他の指標より多くを説明する」という期待と**逆方向**の結果。

**partial positives**:
- F 正則化実験: DistilBERT/SST-2 で弱い正則化 (α=0.001) で +0.33pt の改善
- 閾値設計（percentile vs absolute）に敏感、ベースラインとの順位が入れ替わるケースあり
- 介入実験では ΔF と下流性能の連動を観測

**解釈と対処方針（§9 で詳述）**:
- 構造 probe 依存の SP 指標が**高次元 Transformer で不安定**な可能性
- β₁ 直接指標への切り替え（[insight_beta1_dimension_free.md](thinking/insight_beta1_dimension_free.md)）
- 大規模モデル（Llama 8B, 70B）での検証必要
- 現時点では「修正が必要な段階」と明記する

> 📂 詳細: `experiments/transformer/inference_gedig_v3_layerwise_redefine/`

## 9. 未解決問題と棄却可能性

> **3行要約**:  
> 現時点で load-bearing な仮定と、反証されれば理論が崩れる条件を明記する。  
> 最大の穴: **β₁ の非微分性**、**λ/γ の sensitivity 未検証**、**β₁ の高次元スケーリング未確認**、**Transformer negative result**。

査読者・批評者が指摘する前に、作者自身が open problem として記録する。

### 9.1 load-bearing な仮定（仮定 B1–B4）

本研究の論証は、以下の仮定に依存する。各仮定の検証状況を明記する。

**B1: 三項 (EPC, ΔH, Δβ₁) が構造情報の必要十分な分解である**

- **検証状況**: 例示レベル（Figure 1 で独立性を示した）
- **未解決**: 任意の編集に対する直交性の厳密証明 → [insight_three_terms_orthogonality.md](thinking/insight_three_terms_orthogonality.md) で open problem として記録
- **崩れたら**: 4 項目以上必要 or 3 項目のうち冗長がある → F 分解の骨格再設計が必要

**B2: β₁ が位相情報の十分な代表である**

- **検証状況**: 連結グラフでは β₁ = E - V + 1 で十分、迷路・OCR で実証済み
- **未解決**: 高次ベッチ数（β₂, β₃）が必要な場面がないか、ハブ構造の検出が十分か
- **崩れたら**: β₁ だけでは不十分、高次ホモロジーの導入が必要

**B3: F < 0 が閃き（意味ある構造変化）を捉える**

- **検証状況**: 迷路・OCR で観測可能（AG/DG 発火が理論予測と整合）
- **未解決**: Transformer での F < 0 が下流性能と連動するか（現時点 negative、§9.5）
- **崩れたら**: F の符号が閃きを捉えていない → ゲート設計の再検討

**B4: AG/DG 二段ゲートが必要十分**

- **検証状況**: OCR で DG が AG の 5 倍の情報効率を示す（§8.3）→ 二段分離の必要性を支持
- **未解決**: 三段以上のゲートが必要な場面、単段で済む場面の境界
- **崩れたら**: ゲート設計の拡張 or 簡略化

### 9.2 β₁ の非微分性問題

**問題**: β₁ は整数量（`E - V + C`）。微分できないため、**通常の backprop に乗らない**。

これは「geDIG を Transformer の動的学習に組み込む」クレームの最大の技術的障壁。

**対処案**:

**A 案（保守的）**: `Δβ₁` を gate 判定のみに使い、勾配を流さない
- 実装は容易
- 「スカラー直接扱い」戦略と整合
- ただし Wake 時の embedding 更新に β₁ を使えない

**B 案（挑戦的）**: Differentiable Persistent Homology（Gudhi, TopologyLayer）に置き換え
- 勾配が流れる
- 計算コストが重い
- β₁ の厳密性が緩む

**C 案（現実的推奨）**: Wake / Sleep で責任分離
- **Wake 時**: 微分可能項（ΔEPC, ΔH）で学習
- **Sleep 時**: β₁ を使ってオフライン再配線
- これは §7.3 の Wake-Sleep-Wake 設計と**自然に整合**

**現時点の推奨**: C 案。作者の戦略（工学実証）と最も整合する。

### 9.3 λ, γ のハイパーパラメータ選定

**問題**: λ, γ は現在 quantile-calibrated（経験的選択）。理論的導出法が未確立。

**未実施の検証**:
- Sensitivity analysis（λ, γ を変化させた時の F と下流性能の感度）
- 最適値の理論的導出（情報幾何学的アプローチ等）
- スケジューリング戦略（§6.2 で温度制御の可能性を論じた）

**崩れたら**:
- λ, γ の選択に対して結果が過敏 → 再現性に問題
- ドメイン間で大きく異なる最適値 → 「スケール不変」の主張が怪しくなる

**次のアクション**: sensitivity analysis を迷路と OCR で実施（1〜2 週間）。

### 9.4 β₁ の高次元スケーリング

**問題**: `d_eff = β₁/V + 1` は**正則 d 次元格子**で検証されているが、
一般グラフ（特に高次元 embedding から構築したグラフ）での有効性は未確認。

**未解決**:
- ランダムグラフでの d_eff の意味
- Transformer attention graph（768次元空間）での β₁ の挙動
- スパース vs 密なグラフでの β₁ スケーリング則

これは **β₁ の次元フリー性**（[insight_beta1_dimension_free.md](thinking/insight_beta1_dimension_free.md)）が
どこまで本当に機能するかの検証問題。

**崩れたら**:

### 9.5 Transformer 実験の negative result の解釈

**問題**（§8.6 で報告）: `delta_r2_struct` が distilgpt2/gpt2/gpt2-medium ですべて**負値**。

**可能な解釈**（どれが正しいかは未確定）:

1. **指標の問題**: structural probe 依存の SP 指標が高次元で不安定。β₁ 直接指標に切り替えると回復するかも
2. **モデル規模の問題**: 小規模モデル（〜345M params）では構造的情報が希薄。大規模モデル（Llama 8B+）で検証必要
3. **理論の問題**: そもそも Transformer の attention graph は geDIG の想定する「知識グラフ」ではない
4. **閾値設計の問題**: percentile vs absolute で結果が反転する敏感さ

**検証方針（優先順）**:
1. β₁ 直接指標への切り替え（structural probe 依存を外す）
2. 大規模モデル（Llama 8B, 70B）での再検証
3. 閾値設計の sensitivity analysis
4. もし全て negative なら、Transformer への適用は **Part 4 で棚上げ**

## 付録 D: 未解決の理論問題 — 構造 ≡ 確率 の等価性

> **本研究の範囲外として記録する open problem**。
> 作者の直観的モチベーションの背景にあるが、数学的厳密化は行わない。
> 理論家（情報幾何、MaxEnt、Kolmogorov 複雑性）の専門領域に委ねる。

### D.1 背景の直観

作者の研究モチベーションの根幹には「**構造と確率は等価である**」という直観がある:

- 構造コストと構造利得を定義しようとしたとき、確率表現への変換（KL, ELBO 等）は**情報の一部を落とす**（§2 Figure 1 で証明）
- 一方、構造を構造のまま扱えば、確率側の情報（ΔH）と構造側の情報（Δβ₁）は**同じ情報利得の二表示**として統合できる
- これは数学的には「構造空間と確率空間の間の何らかの対応（isomorphism or operational correspondence）」を示唆する

### D.2 既存の類縁原理

この直観は既に複数の分野で部分的に定式化されている:

| 分野 | 対応原理 |
|---|---|
| 情報幾何学 (Amari) | 確率分布の多様体と Fisher 計量 |
| Maximum Entropy Principle (Jaynes) | 制約構造 ↔ 確率分布の一対一対応 |
| Markov Random Fields | グラフ構造が確率分布を定義 |
| Kolmogorov 複雑性 / MDL | 情報量 ≡ 最短記述長（構造の最小表現） |
| Boltzmann distribution | `E(x) = -log P(x)`（energy ≡ probability） |
| Persistent Homology の確率化 (Bubenik, Carlsson) | ランダム複体の β₁ が確率分布の位相表現 |

これらは「構造 ≡ 確率」の**部分的定式化**と見なせる。

### D.3 なぜ本研究の範囲外とするか

- 情報幾何や Kolmogorov 複雑性との厳密対応を示すには、個人研究のスケールを超える数学的労力が必要
- 本研究の工学的実証（迷路、OCR、RAG、Transformer）は、この等価性の**厳密証明に依存しない**
- 理論家が将来この等価性を定式化した際、本研究の結果が**その工学的実証例**として位置付けられれば十分
- 現段階で等価原理を前面に出すと、工学的貢献が理論的過剰主張で覆い隠される危険がある

本研究は等価原理を**前提とせず**、**反証もせず**、ただ**工学的に有用なスカラー F を提示する**立場を取る。
