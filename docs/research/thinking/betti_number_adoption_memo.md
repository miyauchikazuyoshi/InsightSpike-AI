# β₁（第一Betti数）採用検討メモ

**日付:** 2026-02-07
**ステータス:** 60-seed実験のASP-β₁相関確認待ち → 確認後、全面移行判断

---

## 1. 背景：SP項の定義問題

F分解 `F(l) = EPC(l) - λ(ΔH(l) + γ·SP(l))` において、SP（Structure Predictability）は
当初「平均最短路長（ASP）の変化」として暫定定義されていた。

**ASPの問題点：**
- 計算量 O(V²⁺)。F分解三項中、SP項だけが突出して重い
- 構造の「結果」（平均距離）であって「構造そのもの」ではない
- トポロジー＋幾何の混合量。構造と確率の分離というF分解の目的と矛盾
- 連続量。離散的な構造イベントを平滑化して情報を失う

---

## 2. β₁の定義と計算

**定義：** β₁ = E - V + C
- E: 辺数、V: 頂点数、C: 連結成分数
- 連結グラフ（迷路等）では C=1 固定、β₁ = E - V + 1

**意味：** 独立サイクル（穴）の数
- 木 → β₁ = 0（穴なし）
- 三角形 → β₁ = 1（穴1つ）
- ベンゼン環 → β₁ = 1
- フラーレン C₆₀ → β₁ = 31

**計算量：** O(1)（連結グラフ）、O(V+E)（一般グラフ、connected components計算）

---

## 3. β₁がSP定義として理論的に優れる理由

### 3.1 位相不変量である
β₁はグラフの連続変形で変わらない。辺の重みや配置に依存しない。
SPが測るべきは構造の位相的性質であり、β₁はそれそのもの。

### 3.2 意味が明晰である
β₁ = 独立サイクル数 = 経路選択の自由度。
サイクルが1つ増える = ある2点間に独立な代替経路が1つ増える = 構造的予測可能性の増加。
ASPの「平均距離が縮んだ」は、なぜ縮んだかを語らない。

### 3.3 離散性が正しい
構造変化は本質的に離散事象。β₁は整数。
「サイクルが1つ生まれた」= Δβ₁ = +1。正確な記述。
ASPの連続的変化は離散的構造イベントを平滑化している。

### 3.4 F分解のスケーリングが整合する
EPC（離散）、ΔH（連続）、β₁（離散）。
F = 離散 - λ(連続 + γ·離散)
構造側（離散）と確率側（連続）の分離が型レベルで保証される。

### 3.5 基本量である
ASPは全対間BFSを集約した派生量。β₁は引き算一回の基本量。
Kolmogorov複雑性の意味で、最短の記述が最も本質的な記述。

## 4. F分解の三項＝三分野の基本単位

| 項 | 数学分野 | 位置づけ | 計算量 |
|---|---|---|---|
| EPC | 組合せ論 | グラフ編集距離。最小操作の数え上げ | O(V+E) |
| ΔH | 情報理論（確率論） | Shannonエントロピー。情報の基本単位 | O(N) |
| β₁ | 代数的位相幾何学 | 第一Betti数。ホモロジーの最低次不変量 | O(1)* |

三項全てが各分野の**原子**（これ以上分解不能な基本量）であり、
全てが**線形以下の計算量**。ASP時代のO(V²⁺)ボトルネックが消滅する。

\*連結グラフの場合

---

## 5. 三つの読み方

### 読み1：EPC - (ΔH + β₁) — 経済学的
コスト対リターン。「これだけ編集して、情報と位相がこれだけ改善した」。

### 読み2：(EPC - β₁) - ΔH — 物理学的
EPC - β₁ = 冗長サイクルを除いた本質的構造変化（骨格の変化）。
そこからエントロピー変化を引く。Helmholtz自由エネルギー F = U - TS の離散版。

### 読み3：(EPC - ΔH) - β₁ — 生物学的
EPC - ΔH = 情報的に説明できない構造変化（情報を流すためでもないのに存在する構造）。
β₁がその残差を説明する。シロアリ塚の換気トンネル、情報処理なしに生まれる位相的秩序。

## 6. 応用ドメインへの展開

### 6.1 NN剪定理論

Dense層のβ₁ ≈ n_in · n_out（巨大）。Sparse層のβ₁は桁で小さい。
剪定とは「ΔHを保ちつつβ₁を最小化する操作」。

**Lottery Ticket Hypothesis の再記述：**
> 当たりくじ = ΔHを保存する最小β₁の部分グラフ（木に近い骨格）

**訓練と推論でβ₁の役割が逆転する：**
- 訓練時：高β₁ = 勾配の代替経路 = 探索に冗長性が必要
- 推論時：低β₁ = 計算の無駄なし = 活用にはβ₁最小が最適

| 操作 | 位相的効果 | β₁変化 |
|---|---|---|
| 辺剪定（weight pruning） | 穴を1つ潰す | Δβ₁ = -1 |
| ノード剪定（neuron pruning） | 穴を大きくまとめる | Δβ₁ ≈ -(deg-1) |
| Dropout | 一時的に穴を拡大 | 訓練時β₁が揺動 |
| Knowledge Distillation | 小さいスポンジに転写 | β₁が桁で減少 |

### 6.2 材料科学

| 構造 | β₁ | 化学的意味 |
|---|---|---|
| ベンゼン C₆H₆ | 1 | 芳香族性の源 |
| フラーレン C₆₀ | 31 | 球面安定性 |
| ダイヤモンド単位胞 | 9 | サイクル冗長性 = 硬度 |
| DNA（n塩基対） | ≈n | 遺伝情報量とβ₁が比例 |

**破壊 = β₁の減少。** 脆性破壊はβ₁の急激な崩壊。延性変形はβ₁を保存した形状変化。
geDIGのスパイク検出が材料破壊の予兆検知に直接使える可能性。

### 6.3 宇宙の大規模構造

Pranav et al. (2017, MNRAS) がcosmic webのBetti数を計測済み。
Vazza & Feletti (2020, Frontiers in Physics) が脳ネットワークとcosmic webの統計的類似を指摘。
F分解は「なぜ似るのか」に対して「同じFを最小化しているから」という説明を与えうる。

### 6.4 Landau型相転移との接続

β₁を秩序パラメータとすれば、FはそのままLandau自由エネルギーの離散グラフ版。
無秩序相（高ΔH、低β₁）→ 秩序相（低ΔH、高β₁）の遷移をFが記述する。

## 7. 計算パラダイムの転換

### 7.1 β₁による変化検出

```
if Δβ₁ == 0:
    skip          # 位相不変。キャッシュヒット。O(0)
else:
    update F      # 位相変化あり。再計算。O(1)
```

β₁が安定な領域 = 「無意識処理」。β₁が変化した場所だけ = 「意識的処理」。
Fristonの自由エネルギー原理に計算可能な判定基準（Δβ₁ ≠ 0）を与える。

### 7.2 有効次元の導出

正則d次元格子で β₁/V ≈ d - 1。したがって：

> **d_eff = β₁/V + 1**

要素数Vとβ₁から系の有効次元が復元できる。O(1)の計算。

**応用：エージェントの動的次元拡張**

| 状態 | d_eff | 必要な埋め込み次元 |
|---|---|---|
| 学習初期（木構造に近い） | 1.2 | 128次元で十分 |
| 知識増加（サイクル増加） | 3.5 | 512次元 |
| 専門知識が密に | 7.8 | 1024次元 |

d_effが現在の埋め込み次元を超えたら拡張、下がったら縮小。
**β₁が「何次元で計算するか」を決める。**

### 7.3 次元マスキング

思考時に無関係な情報次元をマスクする理由：
タスクに関与するサブグラフのβ₁から d_eff を計算し、その次元だけ活性化。

### 7.4 動的計算グラフ（NNの未来像）

現行NNは入力によらず全層・全ニューロン発火（All-to-All）。
β₁ベースでは：

- **どこを計算するか** → Δβ₁ ≠ 0 の場所
- **何次元で計算するか** → d_eff = β₁/V + 1
- **残りは** → マスク（計算スキップ）

計算量が入力の難しさに比例する。簡単な問題 → 少層発火、困難な問題 → 多層発火。

### 7.5 TSP等の組合せ最適化

人間のTSP直感は「β₁=1の大きなループを先に知覚→局所調整」。
位相を先に決めることで探索空間がn!からnの局所並べ替えに縮小。
β₁ > 1 の部分解は冗長辺を含む → O(1)判定で枝刈り可能。

### 7.6 グラフの次元フリー性

グラフは隣接行列 A ∈ {0,1}^{V×V}。元空間の次元を完全に忘れる。
768次元空間の点群も3次元空間の点群も、グラフ化後のβ₁計算は同一。
**次元の呪いが消える。** F分解は次元フリー。
