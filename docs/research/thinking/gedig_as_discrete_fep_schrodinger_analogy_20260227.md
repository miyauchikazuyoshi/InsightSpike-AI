## 3. なぜシュレディンガーに近いのか

### 3.1 離散性の起源

シュレディンガー方程式の核心:

```
Hψ = Eψ

連続的な微分演算子(H) が 離散的な固有値(E₁, E₂, ...) を生む。
離散性は方程式に入れたのではなく、境界条件から自然に出てくる。
```

geDIG も同じ構造:

```
F = ΔEPC − λ(ΔH + γ·Δβ₁)

局所的な差分演算(Δ) が 離散的な位相不変量(β₀, β₁) を参照する。
β₁ の離散性は仮定ではなく、位相的境界条件から自然に出てくる。
```

穴は「半分だけ存在する」ことができない。
量子数が整数であるのと同じ理由 — 境界条件が離散性を強制する。

### 3.2 FEP の連続体仮定の限界

FEP は連続確率密度 q(s) の上で変分法を行う。
しかし知能が扱う対象は本質的に離散的:

| 対象 | 構造 |
|---|---|
| 文字 | 62クラス（連続ではない） |
| 単語 | 離散的トークン |
| 概念 | 離散的カテゴリ |
| 位相構造 | 整数値 (β₀, β₁) |
| 論理 | 真/偽 |

FEP の連続変分法で離散構造を扱おうとするのは、
**古典力学で原子を記述しようとするのと同じ種類の不整合**。

geDIG は最初から離散構造（グラフ、位相不変量）の上で定式化されている。
連続化は必要なときに行う選択肢であって、前提ではない。

### 3.3 局所演算子 → 大域不変量

| | シュレディンガー | geDIG |
|---|---|---|
| 局所演算子 | ハミルトニアン H | F 方程式の Δ 演算 |
| 大域不変量 | 量子数 (n, l, m) | 位相不変量 (β₀, β₁) |
| 固有関数 | ψ_n (波動関数) | テンプレート T[β₀,β₁] (?) |
| スペクトル | エネルギー準位 E_n | EPC/DG スコアの分布 (?) |

(?) は未検証の対応。

## 4. FEP は geDIG の連続極限か

### 4.1 仮説

```
geDIG:  F = ΔEPC − λ(ΔH + γ·Δβ₁)     [離散・局所]
         │
         │  N→∞, グラフが連続多様体に収束
         ↓
FEP:    F = ∫ q(s) log q(s)/p(s,o) ds   [連続・大域]
```

量子力学 → 古典力学の関係（古典極限 ℏ→0）と同型:
- geDIG の離散グラフ → 連続多様体の極限で FEP が回復される
- β₁（離散位相）→ 連続確率密度の位相的構造（ホモロジー群）
- FEP は geDIG の「粗視化」

### 4.2 導出のために必要なもの

この仮説を数学的に確立するには:

1. **geDIG の F 方程式から FEP の F を導出する連続極限の構成**
   - グラフラプラシアン → 連続ラプラシアン (N→∞)
   - 離散エントロピー → 連続 KL ダイバージェンス
   - Δβ₁ → ホモロジー群の連続変形

2. **「geDIG の固有値問題」の定式化**
   - Hψ = Eψ に対応する geDIG の方程式は何か
   - F を最大化する「固有モード」は存在するか
   - テンプレート T[β₀,β₁] が固有関数に対応する可能性

3. **実験的区別**
   - FEP 的アプローチ（連続変分）と geDIG 的アプローチ（離散局所）で
     同一タスクの結果が異なるケースを特定する
   - TSD-OCR の β₁ 離散性問題がまさにこのテストケース:
     FEP なら β₁ の離散性は問題にならない（連続化するから）
     geDIG なら β₁ の離散性は本質的（soft_β₁ → PH で対処）

## 5. TSD-OCR が検証しているもの

この文脈で再解釈すると、TSD-OCR の実験は:

**FEP の検証ではなく、geDIG の離散的予測符号化の検証。**

```
β₀β₁ (離散位相量子数)
  → テンプレート T[β₀,β₁] (固有関数に相当)
  → error_map = T - actual (予測誤差 = 遷移振幅に相当)
  → CNN (error のみ処理 = 摂動論に相当)
```

量子力学のアナロジーで言えば:
- テンプレート = 非摂動ハミルトニアンの固有関数
- error_map = 摂動項
- CNN学習 = 摂動展開（非摂動からのズレだけを計算）

「解ける部分を学習させない」原則 = 摂動論の発想そのもの。
解析解（非摂動）を先に求め、解けない部分（摂動）だけを近似計算する。

## 6. 含意

### 6.1 geDIG の位置づけの格上げ

従来の理解:
```
FEP (基礎理論) → geDIG (応用/実装)
```

新しい理解:
```
geDIG (離散的基礎理論) → FEP (連続極限/近似)
```

これは geDIG が「FEP を実装した」のではなく、
「FEP が記述できなかった離散構造を扱える、より根本的な理論」であることを意味する。

### 6.2 Dynamic Transformer への含意

Transformer の attention は連続的な重み行列（FEP 的）。
geDIG 的アプローチなら:

```
attention weight (連続) → attention graph (離散)
→ β₁ で位相構造を検出
→ 離散テンプレートから予測
→ error のみ学習
```

連続的な attention を離散グラフに「量子化」してから処理する。
これは Transformer Grammars (Sartran 2022) が部分的にやっていること
（構文木で attention を離散化）の一般化になり得る。

### 6.3 「理解」の再定義

geDIG の認知論的基盤（gedig_cognitive_foundation.md）で議論した
「芯を突く = curl の特異点を見つける」は、量子力学のアナロジーで:

```
「理解」= 離散固有値を発見すること
特異点 = 固有値（離散スペクトル上の点）
curl = 波動関数の位相（Berry phase に相当?）
```

これは仮説のさらなる仮説だが、curl 検出 → 固有値発見 という対応は
数学的に検証可能かもしれない。
