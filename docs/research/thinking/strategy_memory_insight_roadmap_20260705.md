## 1. RAG → agent memory の看板掛け替え(合意)

- 素朴な RAG(チャンク→ベクトル検索→詰め込み)は 2026 年時点で退潮(長コンテキスト・agentic search)。
  **しかし問題は消えておらず、agent memory(エージェント長期記憶の管理)として主戦場化**。
- geDIG の主張は最初から「what to retrieve」ではなく「**when to accept / restructure / forget**」
  (v6.1 Abstract)。Sleep-RAG 構想の実体も検索改善ではなく記憶の自律管理。
- **掛け替えコストはゼロ**。以後、応用軸の名称は「agent memory」とし、地形図は
  [references/agent_memory_landscape_2026.md](../references/agent_memory_landscape_2026.md) を一次参照とする。

## 2. 従属変数の転換宣言

タスク性能(歩数・精度)は足場であり目的ではない。測るべきは**接続イベント**:
発生率・正しさ・**前後の性能の離散ジャンプ**・提示精度(システムが人間に「A と B は繋がって
いないか」と出す形)。「時間軸の押し込め批判」の実証はここで回収される。

## 3. 「コンテキスト間の閃き」の操作的定義と 4 段階

geDIG 語彙: 別文脈で形成された 2 つのサブグラフが、跨いで初めて解が成立する状況で、
自発的に接続提案(想起)され、F<0 でコミットされる(閃き)= **Case A(Δβ₁=+1、
2 つの独立経路が閉じる)**。

| 段階 | 内容 | 実装土台 |
|---|---|---|
| 1 | 閃きの離散観測 — DG ショートカット発火を閃きイベントとして計測(前後の性能ジャンプ) | 現行迷路のまま |
| 2 | **部分知識の合成迷路** — warmup1 は A 領域のみ、warmup2 は B 領域のみ(封鎖)、eval で全開。ゴールは A+B の縫合でのみ届く | **動的迷路と同じ壁操作機構** |
| 3 | クロス迷路の構造転移 — 迷路 A のパターンを同型の迷路 B で再利用(structural_similarity・graph_pattern_sleep の復活場所) | sleep のモチーフ抽出 |
| 4 | 言語ドメインのマルチセッション記憶 — 別々の会話の 2 事実の接続。外部ベンチ(LoCoMo 系)で「閃きの提示」を評価 = **マッチポンプ卒業試験** | LLM + geDIG メモリ層 |

## 4. 自律改善の実験設計要件と「動的迷路」

要件(v1–v4 の教訓): ①閉ループ ②「朝」がある(ダークルームを環境が罰する) ③改善余地が
事前に測れる ④決定性で paired が効く ⑤安く反復。

**動的迷路**(エピソード k ごとに壁を張り替え)が本命:
- 静的迷路では「正しい記憶を作る」までしか問えない。**自律「改善」は陳腐化への適応で初めて意味を持つ**
- origin story 167 行「F > 0 が続くエッジは刈り込む」= **F 裁定エビクションの必然的な検証場**
  (静的環境では刈る理由がない — F 駆動 sleep の検証場が今まで無かった理由)
- 腕: F 裁定で刈る vs 蓄積し続ける vs 全忘却。従属変数: 変化後の再適応速度
- **段階 2(合成迷路)と実装を共有**(壁の動的操作) — 1 つの改修で 2 つの実験場

## 5. 二軸戦略(基礎モデル原理 × LLM 応用)

草稿 2025-09 のタイトル「**単一スカラーで学習と推論を同時運転する**」が二軸の統一原理。
- **軸1(基礎モデル)**: スクラッチ競争ではなく「geDIG 量が学習動力学の制御信号として本物」の
  実証連鎖 — 観測(grokking_curl: β₁/curl が学習イベントを予言)→ 介入(F-guided training、
  符号問題を grokking 知見で解いてから)→ 原理(構造生成ループ = deductive_optimal_nn)
- **軸2(LLM 応用)**: LLM 本体は触らず**外側に geDIG メモリ層**(KG + F 裁定 sleep + Case A 検出)。
  段階 4 の「閃き提示」が実用形
- **両軸は同じ基礎量**(F・値固定化・Case A・エビクション)を使う。校正場は迷路

運転方針: 迷路土台は直列(v5 → geDIG 量置換 → 動的迷路)、grokking_curl は並行戦線、
LLM 層は段階 2 が定量的に動いてから(routing Stage A の教訓: ノイズの海に早く出ない)。

## 6. Transformer 実験 3 本柱の評価(戦略判断)

| 設計 | 評価 |
|---|---|
| F-trajectory 観測 | 弱い(相関のみ、差別化が「β₁ を足した」止まり) |
| F-regularization 介入(v7 Phase 1 T1) | 筋が悪い(符号未決着+negative control 敗北歴) |
| **grokking_curl** | **圧倒的に筋が良い**(離散イベント・先行への再現+拡張・鋭い予測・決定的で安い・SOP 移植可) |

→ **v7 plan の Phase 1 を grokking_curl 優先に見直す提案**(著者判断待ち)。
