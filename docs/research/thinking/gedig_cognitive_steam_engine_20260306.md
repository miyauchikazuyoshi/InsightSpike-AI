## 1. 中心比喩

geDIG で作る AI は、単に「自由エネルギーを読む」系ではなく、

> **不確実性を、再利用可能な構造へ変換する認知的蒸気機関**

として読めるのではないか。

この比喩の意図は、

- Transformer / LLM の巨大な統計的混合
- geDIG の AG/DG による選別
- Sleep による圧縮・固定化

を、単なる観察でなく **仕事を取り出す循環系** として捉え直すことにある。

---

## 2. なぜ「蒸気機関」なのか

蒸気機関の本質は、

- 熱そのものではなく
- 熱を方向づいた work に変える構造

にある。

同様に、認知でも重要なのは

- 不確実性そのものではなく
- 不確実性から構造更新という有効仕事を取り出すこと

にある。

geDIG はまさに、

- 何が曖昧か
- どこで探索を開くか
- どの更新をコミットするか
- どの経路を圧縮するか

を明示することで、認知に「機関」としてのサイクルを与える。

---

## 3. Transformer は巨大な釜、geDIG はピストン構造

この比喩をさらに具体化すると、

- **Transformer / 大規模モデル** = 巨大な釜、熱浴、統計的混合場
- **geDIG** = ピストン、バルブ、仕事取り出し構造

と読める。

### 3.1 Transformer 側

Transformer は、

- 全体として極めて大きな相互作用を許し
- 多数の可能性を同時に保持し
- 確率的に豊かな表現を作る

という意味で、巨大なボイラーに近い。

しかし、それだけでは

- どの不確実性を使うか
- どこで探索を止めるか
- どの構造を残すか

は明示されない。

### 3.2 geDIG 側

geDIG はそこに、

- AG: 圧力上昇の検知
- DG: 有効仕事としてのコミット
- Sleep: 圧縮と再配線による効率化

を入れる。

つまり geDIG は、統計的熱浴に **方向を持った仕事変換機構** を与える。

## 4. 対応表

| 蒸気機関 | geDIG / 認知系 |
|---|---|
| ボイラー / 熱浴 | LLM / Transformer の巨大な確率場 |
| 圧力 | 曖昧さ・高エントロピー・未整理の張力 |
| ピストン | AG/DG による構造更新サイクル |
| バルブ | accept / reject / hold の切り替え |
| 仕事 | 橋渡し、shortcut、再利用可能構造の生成 |
| コンデンサー | Sleep による圧縮・固定化・剪定 |
| フライホイール | 蓄積された memory / persistent graph / internalized pathway |

---

## 5. AG/DG を機械要素として読む

### 5.1 AG = 圧力検知

AG は、

- 0-hop で「今のままでは曖昧」
- 「ここで探索を開くべき」

を判定する。

これは、機関における

- 圧力上昇
- 弁の開放条件

に相当する。

### 5.2 DG = 有効仕事への変換

DG は、

- multi-hop で本当に shortcut が成立したか
- 構造変更コストに見合うか

を確認し、コミットする。

これは「ただ熱い」だけではなく、

- 実際にピストンを押し
- work を取り出せた

瞬間に対応する。

### 5.3 Sleep = 機関の効率化

Sleep は、

- 使われた経路の圧縮
- 冗長経路の削除
- 次回 0-hop への内在化

を担う。

これは熱機関で言えば、

- 熱を捨てるだけでなく
- 次のサイクルの効率を高める再編成

に近い。

---

## 6. 認知的蒸気機関としての geDIG の核心

この比喩で最も重要なのは、

> **不確実性そのものは価値ではない。  
> 不確実性から、再利用可能な構造を抽出して初めて work になる。**

という点である。

現在の大規模モデルは、強力な熱浴ではある。  
しかし geDIG 的な見方では、それだけでは

- 釜は熱い
- だが仕事変換機構が弱い

状態と見なせる。

geDIG はそこに

- 探索の開始条件
- コミットの条件
- 圧縮の条件

を与え、認知を **cycle** として閉じる。

---

## 7. 導入先として自然な場所

この比喩は抽象的だが、導入先はかなり具体的である。

### 7.1 即効性の高い場所

- dynamic RAG の accept / reject
- memory graph の更新判定
- agent の branch commit / rollback
- long-context の chunk 採否
- KV cache の block 単位保持 / 圧縮 / 破棄

ここでは geDIG は、巨大モデルの上に載る「認知的ピストン」として機能する。

### 7.2 中期

- attention graph の診断
- layer skip / deepen の制御
- Wake で探索された経路を Sleep で FFN 的に内在化

ここでは `dynamic_transformer_spec.md` の話と自然につながる。

## 9. まとめ

geDIG を蒸気機関になぞらえると、

- Transformer は巨大な熱浴
- geDIG はピストンとバルブ
- AG は圧力検知
- DG は有効仕事の抽出
- Sleep は再編成と効率化

となる。

この比喩の価値は、geDIG を

- 単なる評価関数
- 単なる自由エネルギー風の式

としてではなく、

**曖昧さを構造へ変換する循環機構**

として見せられることにある。

その意味で、geDIG で作る AI は

> **認知的蒸気機関**

と呼べるかもしれない。
