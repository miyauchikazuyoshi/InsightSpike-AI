## 1. 問題設定

### 1.1 言語の基本単位問題

通常の理解:
```
単語 → 組み合わせ → 言語 → 経験記述
```

本議論での定式化:
```
エピソード → 変換形式としての単語 → 言語
```

単語は言語の基本単位ではなく、**エピソード(連続的経験の塊)を離散化するための変換器**として位置づける。

### 1.2 集合論的形式化

**2層構造としての E**(重要な前提):

- **エピソード空間 E**: 連続的位相空間(高次元、可能な経験全体の多様体)
- **個々のエピソード e_i ∈ E**: その空間内の離散的単位(識別可能な「1経験」)

この2層構造は比喩ではなく、形式化の必要条件である:

| レベル | 性質 | 必要な理由 |
|---|---|---|
| 空間 E | 連続(位相空間) | β₁ 等の位相的議論、類似度、近傍概念を定義するため |
| 要素 e_i | 離散(識別可能な単位) | 集合論的交差 f = ∩ を well-defined にするため |

類比:物理の位相空間(連続)とその上の離散的状態、関数空間(連続・無限次元)とその上の離散的関数、統計的多様体(連続)とそのサンプル(離散)と構造的に同型。

- **単語空間 W**:離散、低次元、文脈抽象
- **符号化** f: 複数の離散エピソード {e_1, e_2, ..., e_n} ⊂ E を受け取り、単語 w ∈ W を生成
- **復号** g: 単語 w ∈ W を受け取り、エピソード候補 e' ∈ E を生成
- f と g は**非対称な操作**であり、g は f の逆写像ではない

**観察(2026-04-24 追加)**: f の well-definedness は「エピソードが離散単位として識別可能」であることに依存し、g の実装可能性は「エピソード空間 E が連続的位相を持つ(近傍からのサンプリングが意味を持つ)」ことに依存する。2層構造のどちらが欠けても単語の定式化は崩壊する。これは「E が連続かつ e_i が離散」という2層構造が geDIG の形式的前提として必須であることを示す。

### 1.3 単語の生成則(f の定義)

単語 w は複数エピソードの共通部分として生成される:

```
w = f({e_1, e_2, ..., e_n}) = e_1 ∩ e_2 ∩ ... ∩ e_n
```

(∩ はエピソード構造の共通部分抽出、集合論的交差に対応)

名詞化 = ブロック切り出し = エピソード集合からの共通構造抽出。

### 1.4 復号の生成則(g の定義)

受信者は単語 w を受け取り、**自身のエピソード集合 E_B から w を共通部分として含むエピソード群を呼び出し、そこから復号候補を生成する**:

```
g_B(w) = sample({e ∈ E_B | w ⊂ e の構造})
```

復号は f の逆ではなく、**受信者のエピソード集合を参照した再構成**である。したがって:

- 送信者 A の元エピソード e_A と、受信者 B の復号エピソード e'_B は、**原理的に一致しない**
- 一致度は A と B のエピソード集合 E_A, E_B の重なりに依存する
- f による情報損失は不可避(非可逆圧縮)

## 2. 対話過程の MH 的定式化

### 2.1 Metropolis-Hastings の基本フロー(おさらい)

MH は目標分布 p(x) からサンプリングするための MCMC 手法:

```
1. 初期状態 x_0 を設定
2. 反復 t = 0, 1, 2, ...:
   a. 提案分布 q(x' | x_t) から候補 x' を生成
   b. 受容確率を計算:
      α = min(1, [p(x') · q(x_t | x')] / [p(x_t) · q(x' | x_t)])
   c. 一様乱数 u ~ U(0, 1) を生成
   d. u < α なら採択: x_{t+1} = x'
      u ≥ α なら棄却: x_{t+1} = x_t
3. 十分な反復後、{x_t} は p(x) からのサンプル列となる
```

本質的特徴:
- **局所的な提案**による探索
- **目標分布での確率比**による採択判定
- **詳細釣り合い**により定常分布が p(x) に収束

### 2.2 対話過程への対応

1.2-1.4 の集合論的形式化を MH の枠組みに埋め込む。

**設定**:
- A は目標エピソード e_A ∈ E_A を B に伝達したい
- B の現在の内部状態(推定エピソード) x_t ∈ E_B
- 目標: x_t を e_A に「十分近い」e'_B に収束させる

**対応関係**:

| MH の要素 | 対話過程の要素 |
|----------|---------------|
| 目標分布 p(x) | e_A を中心とする B の状態空間上の分布(B が e_A を正しく復号できている度合い) |
| 現在状態 x_t | B の現在の復号エピソード |
| 提案分布 q(x' \| x_t) | A の発話 w が B に誘発する次の候補(A の f による単語化と、B の g による復号の合成) |
| 候補 x' | B の新しい復号エピソード e'_B |
| 採択判定 | e'_B が B のエピソード集合 E_B と整合するか(尤度的な受容) |
| 反復 | 発話-応答-再発話の連鎖 |

**反復過程の具体形**(1.3 の f と 1.4 の g を使って書き下す):

```
ステップ t:
  A は自身のエピソード群 {e_a1, ..., e_an}(e_A を含む)から
    w_A = f_A({e_a1, ..., e_an}) = ∩ e_ai を抽出
  A → B に w_A を送信

  B は w_A を受信し、
    e'_B = g_B(w_A): E_B 内で w_A を共通部分として含むエピソードから候補生成
  B は現在の推定と e'_B の整合性を評価(採択判定に対応)

  B は自身の理解を単語化:
    w_B = f_B({e'_B, ...}) を A に返送

  A は w_B を受信し、
    e''_A = g_A(w_B) で B の理解を再構成
  A は e_A と e''_A の差分を評価し、次の発話 w_A' を調整
```

**収束条件**: e_A と e''_A の差分が許容閾値を下回る(あるいは B の復号 e'_B と e_A が十分近い)。

### 2.3 圧縮-復号の非対称性

重要な構造的特徴:

- f(エピソード集合 → 単語)は**多対一の圧縮**で情報損失を伴う
- g(単語 → エピソード)は**一対多の展開**で、受信者固有のエピソード集合に依存
- ゆえに **f⁻¹ ≠ g** であり、原理的に完全復元は不可能
- 対話の反復は、この非対称性を**複数の単語交換で埋め合わせる**過程

## 3. MH との本質的な差異

### 3.1 記述レベルの違い

MH は**確率分布上の操作**として対話を記述する。
しかし実際に動いているのは**グラフ構造の擦り合わせ**である。

| MH | geDIG的記述 |
|----|------------|
| 連続的確率分布 | 離散グラフ構造 |
| 静的目標分布へのサンプリング | 動的な構造整合化 |
| 確率的採択 | β₁変化による構造判定 |

### 3.2 目的の違い

- MH: 固定された目標分布 p(x) からサンプルを得る(サンプリング問題)
- 対話: 受信者の状態を送信者の意図に収束させる(整合化問題)

両者は形式的に似るが、目的関数が異なる。

### 3.3 確率的記述の限界

MH は計算上便利だが:
- グラフの具体的構造を追跡できない
- 個別事例での構造的誤解パターンを扱えない
- β₁ 等の位相的特徴を直接扱えない

## 4. geDIG F 式との接続

### 4.1 第三読解の採用

F 式のカッコの位置を変えて:

```
F = (EPC - Δβ₁) - ΔH
```

既存メモで「phase transition 方程式」と位置づけられているが、対話過程の文脈で再解釈可能。

### 4.2 各項の対話的解釈

- **EPC**: 探索による情報獲得(新しい発話・応答)
- **Δβ₁**: 構造的理解の変化(グラフ同型性の進展)
- **ΔH**: エントロピー変化(不確実性の減少)

### 4.3 理解到達の条件

**構造的理解(グラフ同型)が達成された時、ΔH → 0**

- A と B のグラフが同型 → 任意の w に対する B の復号の不確実性ゼロ
- 構造の乖離 → 同じ発話が複数候補を生み ΔH > 0
- 対話の進行 = Δβ₁ の整合方向への変化 = ΔH の低下

### 4.4 F 式の収束

- 構造整合化: β₁ の整合化進行
- 理解到達: ΔH → 0 に漸近
- F は EPC - Δβ₁ に収束

## 5. 留保事項

### 5.1 グラフ同型性の強さ

完全な graph isomorphism は計算的に困難(準多項式時間)。
実用的には:
- 部分グラフ同型 (subgraph isomorphism)
- 近似同型 (graph edit distance が小さい)
- タスク依存の許容閾値 ε で ΔH → ε

→ 「部分等号」概念と整合

### 5.2 H と β₁ の独立性

F 式では H と β₁ は独立項として扱われる。
しかし対話過程では両者が連動する可能性。

- 独立モデル: F = EPC - λ(ΔH + γ·Δβ₁)、H と β₁ は独立変動
- 連動モデル: H = H(β₁)、β₁ から H が決まる
- 現実: 相関するが独立(完全連動ではない)

**実証的検証可能な問い**: 対話過程で β₁ と H の軌跡をプロットし相関構造を調査。

### 5.3 ΔH → 0 の望ましさ

常に望ましいとは限らない:
- 教育: 意図的に ΔH を上げて学習を促す
- 創造: 意図的誤解が新解釈を生む
- 発散思考: 収束より発散を優先

→ F の最小化は基本目標だが、対話種類により**動的制御**が必要

### 5.4 確率的記述 vs 離散構造的記述

両者はトレードオフ関係、目的依存:
- 確率的: マクロ挙動の解析、統計的取り扱い
- 離散構造的: 個別誤解パターン、構造的診断

MH が「間違っている」のではなく、geDIG の問題設定では異なる記述レベルが必要。

## 9. 先行議論との対応

本議論の定式化は、以下の既存理論と構造的に同型:

- **Saussure の差異体系**: 単語の意味は他の単語との関係に存する
- **Peirce の semiosis**: 記号→対象→解釈項→新記号の動的連鎖
- **Wittgenstein 後期**: 言語ゲーム、生活形式中心の意味論
- **Bakhtin の発話理論**: 言語の単位は対話的発話である
- **Carnap の intension**: 概念の内包の形式意味論
- **Rosch のプロトタイプ理論**: カテゴリの中心事例
- **Predictive Processing**: 生成モデルによる受信信号の説明
- **Tomasello の使用基盤アプローチ**: 言語獲得の発達的順序
- **Tulving のエピソード記憶**: 意味記憶に先立つ原初的記憶

**内容としての新規性は限定的**(既知の洞察の再発見)。
**定式化の独自性**: 集合論的二ステップ(共通部分抽出 + 復号エピソード生成)で既存諸理論を統合。
**geDIG への貢献**: F 式第三読解との構造的対応を提供。

## 10. 統合的診断

言語の不完全性の根本原因 = **エピソード→単語変換の非可逆性**

一連の言語的現象が、この単一原因から派生する:

- **意味論的過負荷**: 異なるエピソード集合の共通部分が一つの単語に混合
- **被覆の欺瞞**: 単語の外延が全エピソード空間を被覆すると誤認
- **循環論法**: 単語の定義に特定エピソードが暗黙に含まれる
- **等号と合同の混在**: 単語 = エピソード と書く時、実は部分等号

これらは対話的反復による整合化で部分的に克服可能だが、完全な克服は f の非可逆性ゆえ原理的に不可能。

## 11. 拡張仮説: Transformer 成功の構造的説明

**Status**: 仮線(構造的類比として提示、数学的等価性は未証明)

本メモの枠組みが、Transformer を含む現代 LLM の成功を部分的に説明しうるという仮説。

### 11.1 三つの読み方

**読み方A: Attention は g の近似実装**

1.4 の復号 g_B(w) は「受信者のエピソード集合 E_B から w を共通部分として含むエピソードを呼び出し、そこから候補生成する」操作であった。

Transformer の self-attention は:
- クエリ(現在処理中のトークン)が
- キー(文脈中の他のトークン)との類似度に基づいて
- バリュー(対応する情報)を重み付き集約する

これは g を**連続ベクトル空間で近似実装**していると読める。従来の単語ベース手法(bag-of-words、固定 embedding)は g を持たず、単語を固定意味と結びつける。Transformer の成功は g を動的計算として実装した点にある、という解釈。

**読み方B: Contextualized embedding は f の文脈依存実装**

1.3 の f はエピソード集合から共通部分 w を抽出する操作。Transformer の contextualized embedding は、同じ単語が文脈により異なるベクトルを持つ:

- 単語の意味 = その単語を含む周辺エピソード(文脈)の共通部分
- static embedding → contextualized embedding への移行 = f を固定関数から文脈依存関数へ

**読み方C: 自己回帰生成は対話的反復の内部化**

2.2 で定式化した反復過程(A→B→A→B...)を、LLM の自己回帰生成は**単一モデル内部で自己ループ化**していると読める:
- 前のトークン列を「発話」として受け取り
- 次のトークン候補を「復号エピソード」から生成し
- 生成結果を新しい文脈に組み込む

LLM が長文で一貫性を保てるのは、この内部対話が機能するため、という解釈。

### 11.2 差異と限界

本仮説は **構造的類比**であり、Transformer と本メモの定式化の**数学的等価性は未証明**。重要な差異:

**差異1: エピソード概念の不在**
本メモの E は連続的・身体的・感覚的・時間的に豊富なエピソード空間。LLM が扱うのはテキストトークン列のみで、言語的エピソードという狭い部分集合。

**差異2: 明示的共通部分抽出の不在**
本メモの f は「集合の交差」という明示的操作。Transformer にはこの操作が明示的には存在せず、学習結果として似た機能を獲得している可能性のみ。

**差異3: 対話の単方向性**
LLM は主に「受信→生成」の単方向動作。双方向の反復的整合化(A↔B の往復)はアーキテクチャに組み込まれていない。

### 11.3 説明できる範囲と説明できない範囲

**本仮説で説明できる**:
- 固定単語ベース手法より contextualized 表現が優れる理論的理由
- attention 機構が言語処理に有効な構造的理由
- 事前学習(大規模テキストからのパターン抽出)が機能する理由

**本仮説で説明できない**:
- 具体的性能(最適な層数・次元数)
- スケーリング則
- 創発能力(特定規模で新能力が現れる現象)

本仮説は**Transformer 成功の必要条件の一部**を記述するが、十分条件ではない。他要因(大規模データ、計算資源、最適化手法)が残りを担う。

### 11.4 geDIG への含意

もし本仮説が部分的に正しいなら、geDIG のエピソード基盤実装は**Transformer がすでに成功している領域を再発明するリスク**を持つ。

geDIG の差別化点を明確に保つ必要:

| Transformer | geDIG |
|------------|-------|
| 連続ベクトル空間での近似的 g | 離散グラフ上の明示的構造 |
| 明示的構造特徴なし | β₁ による位相的診断 |
| ブラックボックス性能 | 構造的説明可能性 |

方針:「Transformer と同じことを離散で再実装する」のではなく、「Transformer にできない構造的診断を提供する」方向での差別化。

### 11.5 エピソード起点で省略可能な処理

Transformer の処理を本メモの枠組みで見ると、以下の非効率性が浮かぶ。これらは geDIG がエピソード起点で動作するなら理論上省略可能。

**非効率1: E → W → E' の迂回**

Transformer の各層は、実質的に g ∘ f ∘ g ∘ f ∘ ... という合成を反復している。単語(W)経由で連続ベクトル空間での擬似エピソード復元を繰り返す。f は非可逆ゆえ、各往復で情報損失が発生し、それをパラメータ数と学習データで補償する構造。

geDIG が E 内部の処理で W を経由しないなら、この往復損失と補償コストは回避可能。

**注意**: W の経由は人間対話・テキスト文書処理では不可避。geDIG が W を完全に省略できるのではなく、E 内部処理での W 迂回を回避できる、という限定が必要。

**非効率2: 共通部分抽出の陰的学習**

Transformer では f(共通部分抽出)が明示的操作ではなく、数十億〜数兆のパラメータに分散して暗黙的に埋め込まれる。結果:
- 同じパターンの冗長記録
- 可視化・編集・検証が困難
- 新ドメイン転用時に再学習を要する

geDIG が f をハイパーノード化やグラフ交差で明示的に実装すれば、この冗長性を削減できる可能性。

**非効率3: 全文脈再処理**

LLM の自己回帰生成は各ステップで全文脈を再処理し、計算複雑性は O(n²)。

geDIG の「local β₁ recomputation only」原則(既存メモで確立)を対話的整合化に適用すれば、変化したエピソードの近傍のみ更新でき、全文脈再処理を回避できる。

### 11.6 省略に対する留保

上記の省略可能性には重要な留保:

**留保A: 未知のボトルネック**
「理論的に効率的」でも「実装すると別のボトルネックが生じる」事例は AI 史に多数存在(シンボリック AI の知識獲得、グラフ DB のインデックス、スパース表現のハードウェア最適化)。geDIG のエピソード基盤実装も同様のリスクを抱える。

**留保B: Transformer の「非効率」は機能かもしれない**
- 単語空間の迂回 → 異ドメイン転用性の源泉
- 陰的パラメータ → 明示化不能な微妙パターンの捕捉
- 全文脈再処理 → 遠距離依存性の発見

効率化が汎用性や柔軟性の喪失を招くリスクは考慮すべき。

**留保C: 測定基準の選択**
「効率的」の定義で結論が変わる:
- パラメータ数での効率性 → geDIG 優位の可能性
- 計算時間 → 実装次第
- 学習データ量 → geDIG 優位の可能性
- 汎用性 → Transformer 優位の可能性
- 説明可能性 → geDIG 優位

どの効率性を優先するかは応用次第。geDIG の売りを**説明可能性 + 構造診断**に置くなら、純粋な計算効率は二次的指標として扱うのが戦略的に妥当。

### 11.7 検証方法(仮)

本仮説を検証可能な形に分解するなら:

- **検証候補A**: Transformer の attention パターンを、1.4 の g の操作としてモデル化し、予測精度を比較
- **検証候補B**: contextualized embedding の文脈依存性を、1.3 の f の文脈依存実装として解釈できるかを実験的に検証
- **検証候補C**: LLM の長文生成における一貫性を、内部自己対話の β₁ 動力学として観察

いずれも即時着手の対象ではなく、中長期の研究方向として記録。
