## 1. 概要

三角対照学習（TCL: Triangular Contrastive Learning）は、
従来の対照学習（内積ベース）を外積ベースに拡張する手法の提案である。

本ドキュメントでは、この手法の仮説と検証すべき点を整理する。

---

## 2. 命名の由来

### 2.1 なぜ「三角」か

```
「3次元」という表現は空間の次元数と混同されやすい。
「三角」は外積の本質をより正確に表す：
  - 2辺から第3の方向が決まる
  - 三角形の法線ベクトル
```

### 2.2 三角の多重の意味

```
幾何学的：
  2ベクトル → 三角形を成す → 法線が出る
  = 外積の定義そのもの

サイクル的：
  予測 → 行動 → 観測 → 予測
  3つの頂点が三角形を成す

測量的：
  三角測量 = 2点から第3点の位置を決定
  = 2つの既知から未知を発見

安定性：
  三角形 = 最小の安定構造
  3点で面が決まる
```

## 3. 従来の対照学習との比較

### 3.1 従来の対照学習（内積）

```
正例と負例の「距離」を学ぶ
= 2点間の関係
= 1次元（近い/遠い）

SimCLR, MoCo, CLIP：
  同じもの → 近づける
  違うもの → 遠ざける
  → 内積（コサイン類似度）
  → スカラー値
```

### 3.2 三角対照学習（外積）の提案

```
2つのベクトルの外積を取る
= 両方に垂直な第3の方向が生まれる

通常の対照学習：  a · b = スカラー（似てる/似てない）
三角対照学習：    a × b = ベクトル（次に見るべき方向）
```

### 3.3 比較表

```
          内積（従来）      外積（TCL提案）
─────────────────────────────────────────
出力      スカラー          ベクトル
情報      似てる度合い      新しい方向
学習      距離を最適化      構造を発見（仮説）
初期値    良い初期値必要    ランダムでも可能（仮説）
教師      正例負例が必要    不要の可能性
生成性    なし              次の予測を自動生成（仮説）
```

注意：TCLの列は仮説であり、実験的検証が必要。

## 4. 核心的主張（仮説）

### 4.1 ランダム初期値でも動く可能性

```
外積の性質：

v₀がどんな方向でも
obs₁との外積は「垂直方向」を指す
= まだ見ていない方向

ランダム × 現実 = 未知の方向

仮説：
  最初の一歩がどんなにデタラメでも
  「現実との外積」が必ず新しい情報を生む

  そしてAG/DGが構造を選別する：
    意味のある構造 → F下がる → 保持
    意味のない構造 → F下がらない → 棄却

  ランダムスタート → 外積で方向発見 → F最小化で選別
  → 次第に正しい構造が残る
  → 自己組織化

この仮説の検証は今後の課題。
```

### 4.2 教師信号不要の可能性

```
現在のLLM/NN：
  初期重み → ランダム
  学習 → 大量のラベル付きデータで勾配降下
  構造 → データが与える（教師信号）

三角対照学習（仮説）：
  初期状態 → ランダム
  学習 → 行動と観測の外積でサイクル
  構造 → F最小化が自動選別

必要なもの（仮説）：
  ├── 世界と相互作用する手段（行動）
  ├── 結果を受け取る手段（観測）
  └── 以上。

教師不要、という主張の検証が必要。
```

## 5. 高次元での外積

### 5.1 問題

```
厳密な外積はR³でしか定義されない。
埋め込みはR⁸やR^d。
```

### 5.2 解決案：直交補空間への射影

```
外積の本質を抽出：
  「2つの既知ベクトルが張る部分空間の
   直交補空間への射影」

高次元での実装：
  e₁, e₂ が張る部分空間 S
  新しい方向 = obs の S への直交成分
  = obs - proj_S(obs)
  = 「e₁にもe₂にも含まれない新しい情報」

これはGram-Schmidt的操作で実装可能。
```

### 5.3 実装

```python
def cross_product_high_dim(e1, e2, obs):
    """
    高次元での外積的操作
    e1, e2 が張る部分空間に直交する obs の成分を返す

    注意：これは外積の一般化の一つであり、
    他の定式化も検討の余地がある。
    """
    # e1, e2 を正規直交化
    e1_norm = e1 / np.linalg.norm(e1)
    e2_orth = e2 - np.dot(e2, e1_norm) * e1_norm
    if np.linalg.norm(e2_orth) < 1e-10:
        return obs  # e1, e2 が平行な場合
    e2_norm = e2_orth / np.linalg.norm(e2_orth)

    # obs の e1, e2 への射影を除去
    obs_new = obs.copy()
    obs_new -= np.dot(obs, e1_norm) * e1_norm
    obs_new -= np.dot(obs, e2_norm) * e2_norm

    return obs_new
```

## 6. A1-A3との関係

論文で定義した埋め込み空間の要件（A1-A3）が、
三角対照学習の安定条件と一致するという仮説を検討する。

### 6.1 A1（意味勾配保存）

```
要件：意味的に近いエピソードは距離が近い

TCLへの影響（仮説）：
  → 外積の方向が「意味的に垂直」になる
  → でたらめな方向を指さない
  → 三角の第3頂点が意味的に正しい場所を指す
```

### 6.2 A2（スケール正規化）

```
要件：ノルムが統一されている

TCLへの影響（仮説）：
  → 外積の大きさが比較可能
  → 「この方向がどれくらい重要か」が測れる
  → 三角形の面積 = 探索の優先度
```

### 6.3 A3（局所滑らかさ）

```
要件：微小変化で埋め込みが急変しない

TCLへの影響（仮説）：
  → 外積の方向が安定
  → サイクルが発散しない
  → 三角形が毎ステップ少しずつ回転する（暴れない）
```

### 6.4 対応関係の検証

```
geDIGの動的性 → エピソード性を要求
エピソード性 → A1-A3を要求
A1-A3 = TCLの安定条件（仮説）

この対応関係は、実験的・数学的検証が必要。
「たまたま合っていた」のか「原理的に繋がっている」のかを
区別する必要がある。
```

## 7. 具体的な動作イメージ

### 7.1 迷路の場合

```
エピソード e₁：[位置A, 右に進む, 壁なし, 初訪問, 成功, ゴール]
エピソード e₂：[位置B, 下に進む, 壁あり, 2回目, 失敗, ゴール]

内積（従来）：
  sim(e₁, e₂) = 0.3（あまり似てない）
  → 以上。情報生成なし。

外積（TCL、仮説）：
  e₁ × e₂ の直交成分
  → 「右でも下でもない方向」
  → 「まだ試していない操作」
  → 「左に進むべきでは？」
  → 次の探索方向が自動生成される（仮説）

AG/DGで評価：
  この方向のF値は？
  → F下がる → 採用（DG）
  → F下がらない → 棄却（AG継続）
```

### 7.2 RAGの場合

```
エピソード e₁：[クエリ埋め込み, 文書Aを検索, 類似度高, 頻出, 受容]
エピソード e₂：[クエリ埋め込み, 文書Bを検索, 類似度中, 稀, 棄却]

外積（TCL、仮説）：
  e₁ × e₂ の直交成分
  → 「文書Aとも文書Bとも違う方向」
  → 「まだ見ていない情報源」
  → multi-hopの次の飛び先が自動生成（仮説）

類似度では見つからない遷移を発見できる可能性。
```

## 8. F値との統合

```
三角対照学習のサイクル（提案）：

1. e₁ × e₂ → 新方向 v_new（外積）
2. v_new方向のエピソードを探索（行動）
3. 見つかったe₃のF値を評価
   F = ΔEPC_norm - λΔIG_norm
4. AG判定：Fが閾値以下か？
5. DG判定：構造が改善したか？
6. e₂ × e₃ → 次の新方向（次の外積）
7. ループ

役割分離：
  TCL = 「次にどこを見るか」を決める
  F, AG/DG = 「見つけたものを評価する」
干渉しない（仮説）。
```
