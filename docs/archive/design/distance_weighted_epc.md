# 距離重み付きEPC：理論的厳密化への課題

> **式の位置づけ（簡約式） / Formula Status (Simplified)**: この文書の数式は説明用の簡約式です。正準定義（Canonical）は `docs/gedig_spec.md` です。


## 背景

geDIGの式：
```
F = ΔEPC_norm - λ(ΔH_norm + γ·ΔSP_rel)
```

## 現状の問題

| 項 | 測っているもの | 距離情報 |
|---|---|---|
| ΔH（伸展利得） | 候補分布の広がり | **ある**（重み付き分布） |
| ΔEPC | エッジ追加コスト | **ない**（単純カウント） |

### 不均衡
- ΔHは「どれだけ遠くまで広がったか」を測る
- EPCは「何本追加したか」しか見ていない
- 近くに1本追加も、遠くに1本追加も、同じコスト

これは自由エネルギー対応（F = E - TS）で考えると不自然：
- E（エネルギー）も「どこに」構造を作るかで変わるべき
- 遠くに構造を作る = 高エネルギー状態

## 現状の対処：AG/DG制御

現在はAG/DGゲートが暗黙的に距離を考慮している：

```
理論（式）：距離重みなし
　　↓
制御（AG/DG）：距離を暗黙的に考慮
```

- **AG（0-hop）**：近くの異常を検知
- **DG（Multi-hop）**：遠くのショートカットを厳しく検証

→ DGが実質的に「遠距離エッジは高コスト（=厳しい検証が必要）」を実現

**実用上は動く**が、式レベルでは一貫していない。

## 厳密化の方向性

### Option A: 距離重み付きEPC

```
EPC = Σ w(i,j) · cost(edge_ij)

w(i,j) = f(距離, 類似度, 既存経路長, ...)
```

例：
- **近接エッジ** → 低コスト（当然の接続）
- **遠距離エッジ** → 高コスト（ショートカット、要検証）

### Option B: AG/DGの距離制御を理論的に正当化

- AG/DGが距離に応じた適応的コスト調整を行うことを明示
- ゲートの閾値が距離依存であることを式で表現

### Option C: 両方

式レベルで距離重みを導入し、AG/DGがその実装として機能する構造。

## 検討事項

1. **距離の定義**
   - グラフ上の最短経路長
   - 埋め込み空間でのコサイン距離
   - 意味的類似度の逆数

2. **重み関数の形**
   - 線形：w(d) = α·d
   - 指数：w(d) = exp(β·d)
   - 閾値型：w(d) = 1 if d < θ else γ

3. **計算コスト**
   - 距離計算のオーバーヘッド
   - ΔSPとの重複計算の最適化
