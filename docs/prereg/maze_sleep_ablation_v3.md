## 0. 探索の開示(garden of forking paths の記録)

本 prereg に先立ち、**seed=4 のみ**で探索的ランを 4 本実施した(2026-07-02/03 深夜、
`experiments/maze/results/graph_persistent_dg/_exploratory_negex/NOTES.md`):
- replay + guide off は負例パラメータ 3 通り(既定 / deadend−1.0 / +revisit−0.5)すべてで
  warmup FAIL(500) → **eval OK(440–448 歩)** の引き上げを示した
- off + guide off の対照は eval FAIL(500)、袋小路 16 回
- 負例パラメータ強化の効果はマージナル(448→440)

この探索から、(i) 主予測の方向(replay が引き上げる)、(ii) 負例パラメータは**既定値のまま**登録する
(調整しない)、(iii) **seed=4 は確証実験から除外する**、を確定した。探索は仮説生成であり、
以下の確証には使用しない。

## 1. 主張(検証対象)

> replay 伝播値(軌跡ベース Q backup)は、**goal 報酬が存在しない**(warmup 未達の)場合でも、
> 負例・step ペナルティの値地形が「経験済み(負〜0)/未探索(0)」の相対関係を作ることで
> 未探索領域への探索を誘導し、第 2 エピソードの**到達可能性そのもの**を引き上げる。

- 検証する機構は SPEC §4.4 に設計時から記載のもの: 「正の大報酬がないので伝播値は全体的に低い/負に
  なる → 未探索方向(propagated=0)が相対的に有利 → Wake2 は未探索方向を優先する」
- v2 との対比: v2 は「正例の勾配で最短化」(活用)、v3 は「負例の地形で新天地へ」(探索)。
  両方成立すれば、同一の値再処理機構が warmup の成否に応じて活用/探索を**自動で切り替える**
  ことの実証になる。

## 2. 理論の事前予測

- **P1(Primary)**: warmup 失敗シードにおける eval 成功率: replay > off(両群 guide off)
- **P2**: 同シードにおける eval 袋小路遭遇数(`dead_end_steps`): replay < off
- **P3(操作チェック)**: 伝播ノード replay>0 / off=0、warmup 軌跡の paired 一致(成否・歩数)、
  層別(warmup 成否)が両腕で一致すること
- **P4(副次・新シード再現)**: warmup 成功シードにおいて v2 の P1 方向(eval 歩数 replay < off)が再現される

## 3. 反証条件

| 条件 | 帰結 |
|------|------|
| P1 不成立(成功率差なし or 逆方向) | 「seed=4 の引き上げはシード特異的な偶然」と記録。**引き上げ主張を撤回**し、sleep の実証範囲を v2(warmup 成功時の最短化)に限定する。v2 の成立は不変 |
| P1 成立・P2 不成立 | 引き上げは袋小路回避以外の経路によると記録(機構解釈を保留) |
| P4 不成立 | v2 の再現性に疑義 → v2 §8 に追記し、シード範囲依存性を新たな未解決問題として登録 |
| P3 不成立 | 装置故障。結果無効、修理後再実行 |

事後の矛盾吸収はしない。結果が何であれ §8 に追記する。

## 4. 実験設計

### 対象と層別

- **シード 30–59(30 シード、全実験ラインで未使用)を全数実行**し、
  **warmup の成否で層別**する(warmup は初回エピソードで誘導・伝播と無関係 → 層別は決定的であり
  結果を見た選択ではない)。
  - warmup 失敗シード → **P1/P2 の主対象**(v1 の失敗率 23% から期待 5–9 シード)
  - warmup 成功シード → P4(v2 再現)の対象
- **標本拡張規則(事前固定)**: 失敗シードが 5 未満だった場合のみ、シード 60–89 を追加実行する
  (1 回だけ。それでも 5 未満なら、その標本のまま報告し検出力不足を明記する)。
  これ以外の追加・打ち切りは行わない(optional stopping の排除)。

### 条件(操作は 1 変数のみ)

| | replay | off |
|---|---|---|
| `--sleep-propagate` | `replay` | `off` |
| `--sleep-guide` | `off`(共通) | `off`(共通) |
| 負例パラメータ | **既定のまま**(revisit −0.2, deadend 0.0, step −0.01 — §0 の探索結論) | 同左(未使用) |
| その他 | v2 と同一 | 同左 |

### 統計(変更禁止)

1. **Primary(P1)**: warmup 失敗シードの eval 成功/失敗、**McNemar 正確検定(両側 α=0.05)**。
   記述統計として成功率差と discordant 内訳を報告
2. P2: 同シードの `dead_end_steps` paired 差、Wilcoxon(両側)+ bootstrap CI95(シード 20260704)
3. P4: warmup 成功シードの eval 歩数 paired 差(v2 と同一の方法、打ち切り failure→500)
4. 主検定は P1 の 1 つ。P2/P4 は副次と明記
5. **解析コード**: `experiments/maze/analyze_sleep_ablation_v3.py` を実験実行前にコミット

## 5. 主要指標(変更禁止)

1. **Primary**: warmup 失敗シードにおける eval 成功率の差(replay − off)と McNemar p 値
2. Secondary: 同シードの袋小路遭遇差、warmup 成功シードでの v2 方向の再現、実行時間

## 6. 既知のリスク

- **標本の小ささ**: 失敗シードの期待数 5–9 は McNemar には少ない(全 discordant が replay 側でも
  p≈0.06–0.004)。§4 の拡張規則で最低 5 を担保するが、検出力不足のまま終わる可能性を受容する
  (その場合は効果方向と CI を報告し、判定は「証拠不十分」と記録 — FAIL とは区別する)
- **seed=4 の探索結果は使わない**(§0)。確証はすべて新シード
- **warmup 失敗率の変動**: v1 実測 23% は現行コードでの値。30 シードで失敗が極端に少ない/多い場合、
  拡張規則の範囲で対応する
- パイロットは実施しない(探索 4 ラン + v2 本実験 46 ランで装置・実行時間は既知:
  成功シード約 6 分/ペア、失敗シード約 30–35 分/ペア → 30 シードで約 6–7 時間)
