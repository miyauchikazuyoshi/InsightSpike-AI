# 事前登録: 迷路 sleep v5 — 予算分割 warmup(Wake-Sleep-Wake の反復価値)

> **日付**: 2026-07-05(実験実施前にコミット)
> **状態**: DRAFT — 著者承認で FROZEN に変更し、以後は追記のみ
> **位置づけ**: v4 敗北記録(§8: 彫り込みでは不足 → 探索構造の変更へ)の実行。
> sleep ライン 5 本目。**「sleep の価値は 1 回寝ることではなく、寝て起きてまた寝る反復にある」**
> という Wake-Sleep-Wake サイクルの本義(origin story / core theory §7)の初の直接検証。
> 応用軸との接続: 分野の「忘却・統合」オープン課題([agent memory 地形図](../research/references/agent_memory_landscape_2026.md) §4)
> に向かう前段として、sleep 反復の価値を単純ドメインで確立する。
> **実験装置**: fair-budget wsw-cycles(総 warmup 予算を cycles で均等分割、コミット 54442e5。
> cycles=1 の挙動は過去実験と同一 = スモークで軌跡一致確認済み)+ per-cycle 記録
> (`warmup_cycles` / `warmup_any_goal` メタ)。

## 0. 探索の開示(新 SOP: 5 シード探索の初適用)

v4 失敗層 5 シード(60,61,62,63,74 — 一括 500 歩 warmup で全滅)で cyc=1 vs 2 を探索
(`results/graph_persistent_dg/_exploratory_cycles/` NOTES.md):
- **5/5 で分割優位**: eval 成功 3/5→5/5、歩数平均 421.6→215.2(−49%)、袋小路計 79→31
- **機構仮説の修正(本登録の予測設計に直結)**: 事前仮説「分割→ゴール発見率↑→Pull 獲得」は
  **1/5 でしか成立しなかった**(seed=61 のみ)。残り 4 シードは両 warmup 未達のまま改善 —
  実際の主経路は「中間 sleep の負例地形が 2 回目 warmup を未踏領域へ導き、eval に渡る地形の
  被覆・質が上がる」。**したがって P1 は eval の質(歩数)であり、ゴール発見率は副次に置く**。
  (n=1 探索なら発見率を主検定にして外していた — 5 シード SOP の初配当として記録)
- 探索 5 シードは確証から除外。確証はシード 90–119(全ライン未使用)。

## 1. 主張(検証対象)

> 総 warmup 予算(500 歩)を固定した条件下で、warmup の**予算分割+中間 sleep**
> (W₂₅₀-S-W₂₅₀-S-E)は一括(W₅₀₀-S-E)に対し、**一括 warmup が失敗する迷路**(失敗層)の
> 第 2 エピソード探索の質を改善する。機構: 中間 sleep が 1 回目 warmup の負例地形を固定し、
> 2 回目 warmup の探索を未踏領域へ誘導する(経験の被覆が上がる)。

### 1.1 スコープ限定

- 操作は **cycles 数のみ**(1 vs 2)。ペナルティ・readout・その他は v2/v3 と同一の既定
  (v4 の結果を受け彫り込みは導入しない)。
- cycles=3 以上、適応的分割(成功時は分割しない等)、warmup 予算総量の変更は範囲外
  (P4 の結果次第で v6 候補)。
- 「ゴール発見率の向上」は主張しない(探索で 1/5)。発見率は P2 で記述的に報告する。
- 本実験も「F はまだ活きていない」レベル(F 駆動 sleep は範囲外)。

## 2. 理論の事前予測

- **P1(Primary)**: cyc1-warmup 失敗層における eval 歩数(打ち切り failure→500):
  cyc2 < cyc1(paired、CI95 が 0 を除外、p<0.05)
- **P2(副次)**: 同層の eval 成功率 cyc2 ≥ cyc1(McNemar、記述)+ warmup_any_goal 率
  (発見率、記述のみ — 機構の脇役であることの確認)+ 袋小路遭遇数
- **P3(操作チェック)**: cyc2 腕は wsw_cycles=2・warmup_cycles 長 2・各サイクル ≤250 歩、
  cyc1 腕は長 1・≤500 歩(予算遵守)。両腕とも伝播ノード > 0(replay 稼働)。
  層別(cyc1 腕の warmup 成否)は cyc1 腕内で決定的
- **P4(退行ガード、本登録の最大の焦点)**: cyc1-warmup 成功層の eval 歩数で cyc2 が悪化しない
  (paired 差 cyc2−cyc1 の CI95 上限 < **+30 歩**)。
  **事前に明示する懸念**: warmup に 300–500 歩を要して成功していた迷路は、250 分割では
  両 warmup 未達となり、確立済みの成功層効果(v2/v3 の −39〜−51%)を失い得る。
  これは分割のコストであり、検出されたら隠さず記録する

## 3. 反証条件

| 条件 | 帰結 |
|------|------|
| P1 不成立(CI95 が 0 を含む or 逆方向) | **分割仮説の敗北記録**。探索 5/5 はシード群特異と記録。「sleep の反復価値」主張は迷路では支持されずと記録し、探索構造の変更路線は仕切り直し(warmup 方策自体の変更等へ) |
| P1 成立・P4 退行確定(成功層 CI95 下限 > 0 かつ上限 ≥ +30) | 分割の**全面採用は見送り**。「失敗層に有効・成功層にコスト」という条件付き結論を記録し、**適応的分割**(成功で早期終了・失敗で分割継続)を v6 候補として登録 |
| P1 成立・P4 通過 | 分割を新たな既定構成の候補とし、公開文書へ反映。次段: 動的迷路 or cycles>2 の用量反応(いずれも新規登録) |
| P3 不成立 | 装置故障。結果無効、修理後再実行 |

事後の矛盾吸収はしない。結果が何であれ §8 に追記する。

## 4. 実験設計

### 条件(操作は 1 変数)

| | cyc2(分割) | cyc1(一括) |
|---|---|---|
| `--wsw-cycles` | **2**(250+250) | 1(500) |
| その他全フラグ | v2/v3 と同一(replay + guide off + v6_perseed COMMON_ARGS + extended、ペナルティ既定) | 同左 |

- 対象: **シード 90–119(全ライン未使用)を全数実行**し、**cyc1 腕の warmup 成否**で層別
  (warmup は決定的なので層別は事前確定と等価。cyc2 腕の warmup 構造は異なるため層別には使わない)
- 失敗層(期待 7–12、v4 実測 7/30)→ P1/P2。成功層 → P4
- 標本拡張規則: 失敗層 5 未満の場合のみシード 120–149 を 1 回だけ追加
- 実行: `bash run_sleep_v5_split.sh`(per-seed、cyc2→cyc1 の順で paired)

### 統計(変更禁止)

1. **Primary**: 失敗層 eval 歩数 paired 差(打ち切り failure→500)。Wilcoxon(両側 α=0.05)+
   paired bootstrap CI95(シード **20260706**)
2. P2: 同層成功率 McNemar 正確・発見率と袋小路は記述。P4: 成功層 eval 歩数(同手法、判定は §2 の CI 基準)
3. 主検定は P1 の 1 つ。解析コード `analyze_sleep_v5_split.py` を実験実行前にコミット
   (探索データでスキーマ検証済み)
