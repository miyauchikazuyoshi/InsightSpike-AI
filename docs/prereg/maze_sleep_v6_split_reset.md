### 結果の要旨(事前コミット済み記述フィールドによる分解)

**この実験の中心的所見は、P1 の機械判定文字列が不正確であり、事前に仕込んだ層内分解が
それを正すことである。** §6 で発見喪失コストを、解析スクリプトで `over250`/`lost_disc`/
`identical` フィールドを、いずれも**実行前に**登録しておいたのはこの分解のためだった。

1. **汚染修正は決定的に確証された。** 成功層のうち cyc1-warmup ≤250 の 13 シードは
   **13/13 が eval 完全一致**(diff = 0)。v5 で観測した ≤250 退行(+104)は 100%
   visit_counts 境界跨ぎ汚染のアーティファクトであり、reset で消える — 探索 5/5 が
   確証 13/13 で再現。**「≤250 退行は汚染」という帰属は敗北ではなく成立**。

2. **P1(成功層全体の非劣性)は登録どおり FAIL する。だが原因は汚染残存ではなく、
   §6 で登録済みの発見喪失コストである。** +70.7 の平均と CI 下限 6.1>0 は、
   cyc1-warmup >250 の 6 シードのうち **5 シードが発見喪失**(250×2 の両サブ warmup が
   ゴール未達 → eval 大幅悪化: 125 +412 / 131 +396 / 148 +428 / 141 +104、
   138 は +4 で軽微)に**全面的に起因**する。残る 1 シード(140)は分割 warmup2 が
   ゴールを拾って cyc1 と一致(+0)。**14 の identical ペアの寄与は正確に 0** で、
   退行は 4–5 の発見喪失外れ値だけが作っている。reset は warmup 挙動を変えないため
   この層を救えない — これは分割の真のコストであって、汚染とは別機構。

3. **機械判定文字列の訂正(§6 が許諾した範囲)**: スクリプトは P1 FAIL 時に
   「contamination was not the main cause / 汚染帰属の敗北」と出力するが、**これは
   事実と逆**。汚染は ≤250 で主因であり続け(13/13 で修正が効いた)、P1 FAIL を作るのは
   発見喪失(>250)である。登録した P1 の**構造**(全成功層を 1 検定に束ねた)が 2 機構を
   混合したための誤表示であり、**事後の矛盾吸収ではなく、事前登録済みフィールドによる
   機械的分解**である。

4. **v5 の失敗層救済(−212)は新シードで再現しなかった。** 失敗層 n=11 は中立
   (+10.9、CI が 0 を跨ぐ、成功率 0.45 vs 0.55)。救済 2(135 −380 等)・損失 5・引分 4 の
   高分散。**v5 の救済はシード群特異だった**が確定。

5. **全体(P4)**: 登録 CI 基準では NEUTRAL(分割は全体で優越しない)。ただし
   Wilcoxon p=0.028 は符号上 cyc1 優位に傾く — bootstrap 平均 CI が発見喪失外れ値の
   重い裾で 0 を含む一方、順位検定は identical 多数の下で非ゼロペアの一貫方向を拾う。
   **どちらの読みでも「分割は良くならない、むしろ僅かに悪い」**。

### 事前登録どおりの帰結の執行

- §3 の分岐: P1 は「不成立・退行残存」に該当するが、退行の正体は§6 登録済みの発見喪失で
  あり、分解の結果 **≤250 の汚染帰属は成立・>250 の発見喪失は分割の実コスト**と記録する
- **無条件の予算分割は棄却のまま**(機械結論「unconditional split stays rejected」は
  帰結として正しい — 理由の文字列だけが不正確)。**既定は cycles=1 のまま**
- **reset 修正は本物**(≤250 で確証)であり、**多サイクルを別理由で採る場合の必須の汚染除去**

  シードには効かない(そもそも 250 で成功しないから停止条件に到達しない)。分割路線は
  失敗層対策としても新シードで救済せず、**sleep 反復の価値は迷路では支持されない**と記録
