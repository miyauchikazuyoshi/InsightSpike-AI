## 1. 主張(検証対象)

> エピソード境界リセット(汚染修正)の下では、総予算固定の予算分割 warmup
> (W₂₅₀-S-W₂₅₀-S-E)は一括(W₅₀₀-S-E)に対し、**(i) 一括 warmup が成功する迷路
> (成功層)で非劣**(v5 の退行 +122.5 は汚染という装置欠陥の産物であって、
> 分割そのものの本質的コストではない)、**(ii) 一括 warmup が失敗する迷路(失敗層)
> では v5 で観測した救済方向を保持する**。

### 1.1 スコープ限定

- 操作は「分割+リセット」のパッケージ(cyc2+reset)vs 一括(cyc1)の **2 腕のみ**。
  リセットは cyc1 には構造的 no-op(単一エピソードに境界なし)のため付与しない
- 汚染ありの cyc2(v5 構成)腕は走らせない(汚染の存在と効果は v5 §8 +探索 0b で確立済み。
  reset の単独効果分離を新シードで再確証する 3 腕設計は範囲外)
- cycles=3 以上、適応的分割、wake 側(dim8 revisit 上書き)の修正、warmup 予算総量の変更は範囲外
- **成功層の優越は主張しない**(探索 5/5 identical)。全体優越は P4 の記述的プローブに留める
- 本実験も「F はまだ活きていない」レベル(F 駆動 sleep は範囲外)

## 2. 理論の事前予測

- **P1(Primary、非劣性)**: cyc1-warmup 成功層の eval 歩数(打ち切り failure→500)で、
  paired 差(cyc2reset − cyc1)の **CI95 上限 < +30 歩**(v5 P4 と同一の装置・同一の閾値)。
  探索の示唆する点予測は「差 ≈ 0、identical ペア多数」
- **P2(副次、記述)**: 失敗層の eval 歩数・成功率・発見率・袋小路。方向予測は
  cyc2reset < cyc1(v5 の −212 と同方向)。**検定は登録しない** — v5 §8 で失敗層 n≈6 の
  検出力不足(5勝1敗で p=0.125 が下限)を学習済み。記述と v5 との定性比較に徹する
- **P3(操作チェック)**: cyc2reset 腕は wsw_cycles=2・各サイクル ≤250・
  `sleep_q.episode_boundaries_applied` が**長さ 1 かつ値 = warmup1 実歩数**(リセット発動の
  機械的証跡)。cyc1 腕は長 1・≤500。両腕とも伝播ノード > 0
- **P4(副次、全体プローブ)**: 全 30 ペアの paired 差(両側)。事前の期待は
  **中立**(成功層 ≈0 + 発見喪失シードの小幅 + と失敗層救済の綱引き)。SUPERIOR /
  NEUTRAL / INFERIOR を機械判定で記述(採否判断は P1 が主)

## 6. 既知のリスク

- **発見喪失層の残存コスト**: warmup が 250–500 歩を要する迷路では分割は依然ゴール発見を
  失い得る(reset は warmup 挙動を変えない)。発見できた場合も eval は warmup2 経路水準
  (cyc1 比で小幅 + の余地)。この層が新シードに多いと P1 の CI 上限を押し上げる —
  それは分割の真のコストであり、検出されたら隠さず記録する(v5 §2 P4 と同じ姿勢)
- 新シード 120–149 の層構成は未知(v4: 7/30、v5: 6/30 失敗層。同程度を期待)
- 探索は ≤250 層のみで実施 — >250 層・失敗層での reset 挙動は本実験が初データ
- **パイロット省略の宣言**: 探索 5 本+スモーク 2 本+全 6 実験の実績で装置健全性・
  実行時間(cyc2reset 成功 ~2–5 分/本、cyc1 成功 ~2–15 分/本、失敗シード ~40–70 分/本)は
  既知。総見積 **6–10 時間**
