### 3. 図表キャプションの修正

#### 図1（概念図）
**Before**: 「探索はクエリを中心とした同心円状の波紋として進行する...」
**After**: 「AG（内側軌道，青）は0-hop評価で局所的な不確実性（ΔH↑）を検知し探索を起動する．DG（外側軌道，赤）はMulti-hop評価で経路短縮（ΔSP>0）を発見しエッジを確定する．このAG→DGサイクルにより，高エントロピー状態から低F状態への相転移が生じる．」

#### 図2（AG/DG制御フロー）
**Before**: 「0-hopで『違和感』を検知して探索し，Multi-hopで『近道』を発見して統合する．」
**After**: 「観測→候補生成→AG評価（g₀>θ_AGで探索継続）→DG評価（g_min<θ_DGでコミット）の事象駆動ループ．AGは局所的異常（高F）を，DGは大域的効率化（低F）を検知する．」

#### 図4（迷路探索）
**After**: 「迷路探索における実空間と内部表現の対応（15×15, seed=19）．(a) 実際の迷路と探索軌跡（黄線）．(b) 構築されたエピソード記憶グラフ．直線通路は圧縮され，分岐点（意思決定点）のみがノードとして保持される．候補エッジに対するコミットエッジの棄却率（edge-compression）は98%に達した．」

#### 図5（層別F値）
**After**: 「BERTにおける層別F値の推移（SST-2, n=1000シーケンス平均）．横軸は層番号，縦軸はF値（構造適応度）．破線はランダム行列のベースライン．浅層（Layer 0-1）ではF値が低く高エントロピーな探索状態にあり，深層（Layer 4+）ではF値が上昇し安定した構造化状態に収束する（Layer 0-1 vs 4+: p<0.001）．」

#### 図6（F正則化）
**After**: 「F正則化強度αとSST-2テスト精度の関係（DistilBERT, n=5 seeds, エラーバーは標準偏差）．微弱な正則化（α=0.001）で精度が86.00%→86.33%に改善（p<0.05）．過剰な正則化（α≥0.1）は構造を固定化しすぎ性能を悪化させる．この逆U字特性は適切な構造化圧の存在を示す．」
