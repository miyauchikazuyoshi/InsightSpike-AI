## 1. 核心定義: geDIGの正体 (The "What")

### 「良い構造」とは何か？
geDIGでは、以下の3つの要素のトレードオフで「良い構造（構造適応度 $F$）」を定義します。

1.  **エントロピー ($H$)：『迷いのなさ』**
    *   **定義**: Attention確率分布のシャノンエントロピー。
    *   **意味**: 値が低いほど、どこに注目すべきか確信を持っている（Concentration）。高いと「迷子」（Distraction）。
2.  **処理コスト (EPC)：『配線の少なさ』**
    *   **定義**: 有効エッジの密度 (Edge Processing Cost)。
    *   **意味**: 値が低いほど、無駄な結合がない（Sparsity）。脳で言えば代謝エネルギーの節約。
3.  **通信効率 (SP)：『伝達の速さ』**
    *   **定義**: グラフ全体の平均最短パス長の逆数 (Global Efficiency)。
    *   **意味**: 値が高いほど、遠くの情報も瞬時に統合できる（Integration / Small-world性）。

### 自由エネルギー式 (F-value)
$$F = \underbrace{\text{Value}}_{(\text{低}H + \text{高}SP)} - \underbrace{\text{Cost}}_{(\text{低}EPC)}$$
（※式変形後の直感的解釈）

*   **解釈**: 「最小限のコストで、最大の確信と効率を得る」状態を目指すこと。これが**$F$（構造適応度）の最大化**であり、熱力学的な**自由エネルギーの最小化**と等価です。

## 2. 検証ロジックの統一 (The Unification)

「迷路実験（Action）」と「Transformer実験（Thinking）」は、数理的には全く同じフレームワークで説明できます。

| 項目 | 検証1：迷路/RAG (Action) | 検証2：Transformer (Thinking) |
| :--- | :--- | :--- |
| **対象** | 動的な「行動」の連鎖 | 静的な「推論」の積層 |
| **時間軸** | ステップ $t$ vs $t-1$ | レイヤー $L$ vs Null Graph |
| **差分($\Delta$)** | **時間的差分 (Temporal Delta)**<br>行動によってどれだけ構造が改善したか | **空間的差分 (Spatial Delta)**<br>その層がランダムに比べてどれだけ構造化されているか |
| **本質** | 探索(Explore) $\to$ 利用(Exploit)への相転移 | 入力(Chaos) $\to$ 理解(Order)への相転移 |

## 3. 実験結果のストーリー (The Evidence)

### ① 観測 (Observation): Transformerの相転移
「学習済みBERTをgeDIGで診断したところ、明確な**構造相転移**が観測されました（図3）。」
*   **浅い層**: 「高エントロピー・低F値」。あらゆる可能性を考慮する**探索モード**。
*   **深い層**: 「低エントロピー・高F値」。文法構造を特定し確信する**収束モード**。
*   **含意**: Transformerは単なる行列計算ではなく、熱力学的な構造化プロセスを行っている。

### ② 介入 (Intervention): 因果性の証明
「これは単なる相関ではありません。geDIGを損失関数（正則化項）に加えて『もっと構造化せよ』と圧力をかけたところ、テスト精度が有意に向上しました（+0.33%）。」
*   **結論**: geDIGは、モデルの汎化性能を左右する**因果的な制御パラメータ**である。

## 3.5. 実社会への応用 (The Application)

「この理論は、単なる分析ツールにとどまりません。実際に『役に立つ』ことを実証しました。」

### ① Neuro-Pruning (脳外科手術)
「『浅い層はカオス（低F値）である』という理論に基づき、構造適応度の低いAttentionヘッドを物理的に切除しました。その結果、**Layer 0-1を中心に全体の10%を削減しても性能が維持される**ことが確認されました。理論通り、浅い層は冗長だったのです。」

### ② Structure-Guided RAG (バナナテスト)
「『論理的な文章は三角形（Clustering）を作る』という幾何学的性質を発見しました。これを利用し、**『単語は似ているが意味不明な文章（Word Salad）』を検索結果から排除**することに成功しました（通称：バナナテスト）。これはハルシネーション対策の決定打になり得ます。」

## 4. 防御用Q&A (Defense)

### Q. F値の式、符号が逆では？
**A.** 「本論文では $F$ を『負の自由エネルギー（Structural Fitness）』として定義しているため、『$F$が増える＝エネルギーが減る＝安定化する』という解釈になります。」

### Q. ベースライン（Null Graph）とは？
**A.** 「各層のAttentionと同密度のランダムグラフです。『もし何も学習していなければどうなるか』という基準点に対し、学習済みモデルがどれだけ秩序を形成したか（KLダイバージェンス）を測っています。」

### Q. なぜ迷路とTransformerを混ぜた？
**A.** 「『構造化による推論』という普遍原理を示すためです。マクロな迷路探索も、ミクロな言語理解も、**『不確実性の縮減（エントロピー最小化）』という統一原理**で記述できることを示すのが本研究の狙いです。」
