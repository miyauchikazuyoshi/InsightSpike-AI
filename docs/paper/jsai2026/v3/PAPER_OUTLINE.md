## 2. geDIG: 統一的定義（0.5P）

### 2.1 基本公式

```
F = ΔEPC - λ(s·ΔH + γΔSP)

F < 0: 良い変化（効率的な構造形成）
```

### 2.2 各成分の意味

| 成分 | 定義 | 迷路 | Transformer |
|------|------|------|-------------|
| EPC | 構造変化コスト | エッジ追加数 | Attention変化量 |
| H | エントロピー | 特徴量分布 | Attention分布 |
| SP | ショートカット純度 | ゴールへの経路効率 | CLSへの経路集中度 |

### 2.3 entropy_sign (s) パラメータ

| フェーズ | s | 解釈 |
|----------|---|------|
| 構造構築（迷路、事前学習） | +1 | 延伸が利得 |
| 構造特化（Fine-tuning） | -1 | 集中が利得 |

## 4. Transformer実験（1.0P）

### 4.1 Shortcut Purity (SP) の再定義

**問題**: 全ペア到達性は希釈される
**解決**: アンカートークン（CLS）への経路集中度

```python
SP = top_k_attention_to_CLS / total_attention_to_CLS
```

**図2**: SP定義の概念図（CLSへの経路集中）

### 4.2 実験設定

- モデル: DistilBERT
- タスク: SST-2（感情分類）
- 設定: entropy_sign=-1（Fine-tuning）

### 4.3 介入実験

| 条件 | 精度 | ΔSP |
|------|------|-----|
| Baseline | 86.8% | - |
| **Positive（F↓方向）** | **85.6%** | +0.19 |
| Negative（F↑方向） | 81.0% | -0.09 |

**結果**: Positive > Negative（4.6%差）
→ geDIG Fが有効な学習シグナル

### 4.4 迷路との対応

| 要素 | 迷路 | Transformer |
|------|------|-------------|
| ノード | 状態 | トークン |
| エッジ | 遷移 | Attention |
| アンカー | ゴール | CLS/SEP |
| 学習方向 | 構築（疎→密） | 特化（汎用→タスク） |
