## 6. F値による類似度調整

```
┌─────────────────────────────────────────────────────────────┐
│                  Similarity Adjustment                      │
│                                                             │
│   raw_similarity ◀─── ベクトル距離（生データ）             │
│         │                                                   │
│         ▼                                                   │
│   ┌───────────────────────────────────┐                    │
│   │  F = ΔEPC − λ·ΔIG                 │                    │
│   │                                    │                    │
│   │  ΔEPC: 構造変更コスト             │                    │
│   │  ΔIG:  情報利得                   │                    │
│   └───────────────────────────────────┘                    │
│         │                                                   │
│         ▼                                                   │
│   ┌───────────────────────────────────┐                    │
│   │  adjusted = sim × sigmoid(-F)     │                    │
│   │                                    │                    │
│   │  F < 0 (良い) → 増幅              │                    │
│   │  F > 0 (悪い) → 抑制              │                    │
│   └───────────────────────────────────┘                    │
│         │                                                   │
│         ▼                                                   │
│   adjusted_similarity                                       │
│                                                             │
```
