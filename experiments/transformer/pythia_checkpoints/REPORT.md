# Pythia チェックポイント実験レポート

**実験日**: 2026-02-03
**目的**: geDIGの学習ダイナミクスを、Pythiaの公開チェックポイントを用いて検証

---

## 1. 実験背景

### 1.1 問題意識

事前学習済みモデル（BERT等）でのgeDIG実験では、**SP（Shortcut Purity）が常に高い値**（~0.99）を示し、構造形成過程を観察できなかった。

**解決策**: 学習途中のチェックポイントが公開されているPythiaを使用し、ランダム初期化から学習完了までの全過程を観察する。

### 1.2 仮説

1. 学習が進むにつれて**エントロピー（H）が減少**する（注目先が集中）
2. 学習が進むにつれて**EPC（構造変化コスト）が増加**する（一様分布から離れる）
3. **F値の変化量（ΔF）が単調減少**する（収束）

---

## 2. 実験設定

### 2.1 モデル・データ

- **モデル**: EleutherAI/pythia-70m（7000万パラメータ）
- **チェックポイント**: step 0, 64, 512, 2000, 8000, 33000, 143000
- **テストデータ**: 10個の英文（感情分析ではなく一般的な文章）

### 2.2 geDIG設定

```python
geDIG v2:
- lambda_param: 1.0
- gamma: 0.5
- entropy_sign: -1（集中モード）
- 参照状態: 一様分布
```

### 2.3 制約

- **SPが機能しない**: PythiaはCausal LM（CLSトークンなし）のため、アンカーベースのSP定義が適用不可
- CPU実行（GPU なし）

### 3.3 主要な発見

1. **H（エントロピー）は54%減少**: 1.31 → 0.60
   - 学習により注目先が集中

2. **EPC（構造変化）は30%増加**: 5.74 → 7.43
   - 一様分布から独自の構造パターンを獲得

3. **|ΔF|は単調減少**: 0.75 → 0.09 → 0.08 → 0.06 → 0.01
   - F値の変化が収束

4. **64→512で急激な変化（相転移）**
   - この区間で本格的な構造獲得が発生

## 5. 限界と課題

### 5.1 SP定義の問題

Causal LM（GPT系）には：
- CLSトークンがない
- 全位置が予測点

→ BERTのような「情報集約点」がないため、現行のSP定義が機能しない

### 5.2 代替SP定義の提案

| 案 | 定義 | 実装状況 |
|----|------|----------|
| Top-k占有率 | 上位20%のattention重みの合計比率 | 未実装 |
| 位置ベース | 直近k%トークンへの集中度 | 未実装 |
| Gini係数 | Head別の注目偏り度 | 未実装 |

## 6. 結論

### 6.1 検証できたこと

✅ **H（エントロピー）の減少**: 学習により注目が集中
✅ **EPC（構造変化）の増加**: 独自パターンの獲得
✅ **|ΔF|の収束**: 学習の安定化
✅ **相転移の存在**: 64→512で急激な変化

### 6.2 検証できなかったこと

❌ **SP（ショートカット純度）の変化**: Causal LMでは定義が機能せず

### 6.3 論文への示唆

geDIGを「単調な収束指標」ではなく、**「相転移点の検出器」**として位置づけることが妥当。
