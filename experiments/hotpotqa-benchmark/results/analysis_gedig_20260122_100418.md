# HotPotQA dev geDIG分析メモ（2026-01-22）

## 目的
最新フルrun（geDIG）と既存ベースラインの差分を定量化し、弱点/強みの切り分けと深掘り対象を決める。

## 使ったデータ
- geDIG: `experiments/hotpotqa-benchmark/results/gedig_20260122_100418.jsonl`
- baselines:
  - static_graphrag: `experiments/hotpotqa-benchmark/results/static_graphrag_20260115_231836.jsonl`
  - bm25: `experiments/hotpotqa-benchmark/results/bm25_20260115_115855.jsonl`
  - contriever: `experiments/hotpotqa-benchmark/results/contriever_20260116_075521.jsonl`
  - closed_book: `experiments/hotpotqa-benchmark/results/closed_book_20260113_220125.jsonl`
- 問題メタ: `experiments/hotpotqa-benchmark/data/hotpotqa_distractor_dev.jsonl`

## 分析内容
- **IDで結合**: すべて `id` をキーに結合し、同一サンプルで比較。
- **差分指標**: `ΔF1/ΔEM/ΔSF-F1 = geDIG - baseline` を計算。
- **勝敗判定**: `ΔF1` が `>0` を win、`=0` を tie、`<0` を loss。
- **タイプ別**: `type`（bridge/comparison）ごとの平均/中央値/勝敗数。
- **難易度別**: `level`（devはhardのみ）で同様に集計。
- **質問形式別**: 質問の先頭語で分類（how/how many/what/which...、yes/noは助動詞始まり）。
- **ケース抽出**: `ΔF1` の絶対値が大きい上位例を win/loss で各3件抽出し、
  質問・予測・正解を比較（static_graphrag / bm25）。
