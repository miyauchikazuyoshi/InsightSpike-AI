# BRIGHT CoT-driven Re-retrieval 実験レポート

**日付**: 2026-03-11
**実験ID**: v12 BRIGHT Spec A
**担当**: InsightSpike-AI

---

## 1. エグゼクティブサマリー

BRIGHTベンチマーク（推論集約型文書検索）において、CoT-driven Re-retrieval を実装・評価した。
LLM が生成した Chain-of-Thought の概念を BM25 クエリとして再利用し、元の検索結果 (top-100) に含まれなかった文書を追加取得することで、**nDCG@10 を 0.1219 → 0.1520 (+24.7%, p=0.002)** に改善。BM25 ベースラインからは **+123.2%** の改善。追加 LLM コストはゼロ。

---

## 2. 背景

### 2.1 ボトルネック

v12 Phase 2 (CoT+Graph) の分析で、73% のクエリが nDCG=0 と判明。
根本原因: gold 文書が BM25 top-100 に存在しない。
re-rank の改善は既に飽和に近く、**候補プールの拡大**が最大のレバレッジ。

### 2.2 アプローチ

CoT が生成する推論テキストには、元のクエリに含まれない専門用語・関連概念が含まれる。
これらを BM25 クエリとして再検索し、語彙ギャップ (vocabulary gap) を橋渡しすることで、
元の top-100 外に埋もれた関連文書を発掘する。

---

## 3. 手法

### 3.1 パイプライン

```
[従来 CoT+Graph]
  BM25(query) → top-100 → Graph(50) → CoT → Inject → Score → Re-rank

[CoT Re-retrieval] ★新規
  BM25(query) → top-100 → CoT → Extract concepts
                                → BM25(concepts) → 50 new docs
                                → Merge(150 docs) → Graph(50) → Inject → Score → Re-rank
```

### 3.2 概念抽出と再検索

1. CoT テキストからエンティティ (固有名詞) + 概念語 (2-3語フレーズ) を抽出
2. 長さ降順ソート（長い概念 = より弁別的）→ 上位20概念を選択
3. 概念を結合して BM25 クエリとして再検索
4. 元の top-100 と重複しない文書のみを上位50件取得
5. マージ: 元100件 + 新規50件 = 150件の拡大候補プール

### 3.3 グラフ構築の工夫

graph_top_k (50) のうち 1/5 (10枠) を CoT 取得文書に割り当て。
残り 40枠は元の BM25 上位文書。
→ CoT で発見した文書がグラフのトポロジーに組み込まれ、CoT ノード注入との相乗効果。

### 3.4 パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| cot_retrieval_top_k | 50 | CoT クエリで取得する新規文書数 |
| cot_retrieval_max_concepts | 20 | BM25 クエリに使用する概念数 |
| graph_top_k | 50 | グラフ構築に使用する文書数 |
| rerank_alpha | 0.1 | BM25 vs Graph の重み (graph-dominant) |
| model | gpt-4o-mini | CoT 生成モデル |

## 8. なぜ効果的か — メカニズム分析

### 8.1 語彙ギャップ橋渡し

推論集約型クエリでは、ユーザーの質問と関連文書の間に「語彙ギャップ」が存在する。
例: "Why do insects fly towards light?" → gold 文書は "phototaxis" "positive phototactic response" を含む。
BM25 は単語一致ベースのため、このギャップを超えられない。

CoT は推論過程で "phototaxis", "light sensitivity", "navigation mechanisms" 等の
専門用語を生成 → これらで BM25 再検索することで、元の検索では見つからなかった文書を発見。

### 8.2 相乗効果

1. **CoT → 新文書発見**: 語彙ギャップ橋渡し (主効果)
2. **新文書 → グラフ拡張**: CoT 取得文書がグラフに組み込まれ、トポロジーが豊かに
3. **CoT ノード注入 × 拡張グラフ**: CoT ノードと新文書ノードの接続で、スコアリングが改善
4. **候補プール拡大 → 最終ランキング**: 150件から top-10 を選択 (100件より選択肢が広い)

### 8.3 ゼロコスト設計

- CoT 生成は従来パイプラインと同一 (追加 LLM 呼び出しなし)
- BM25 再クエリはインメモリ計算 (<1ms)
- レイテンシ増加なし (12,069ms vs 12,339ms — 誤差範囲内)

## 10. 結論

CoT-driven Re-retrieval は、推論集約型検索における「語彙ギャップ」問題に対する
効果的かつ低コストな解決策である。LLM が生成した推論概念を再検索クエリとして活用することで、
元の BM25 top-100 では発見できなかった gold 文書を 30% のクエリで新たに発見し、
nDCG@10 を +24.7% (p=0.002) 改善した。追加の LLM コストはゼロ。

SOTA (63.4) との差は依然として大きいが、BM25 (6.8) から4ステップの改善で 15.2 に到達。
各ステップが統計的に有意な改善をもたらしており、この手法の発展性を示している。
